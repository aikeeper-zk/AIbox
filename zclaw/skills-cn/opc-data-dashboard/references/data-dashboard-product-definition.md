## 一句话定位

**数据看板**是运行在小龙虾AI盒子上的统一数据监控工具，让OPC创作者**各平台数据统一看**，知道什么内容能火、什么渠道赚钱、今天比昨天好还是差。

## 核心功能

| 功能 | 说明 |
|------|------|
| 内容数据汇总 | 各平台播放/点赞/评论/收藏统一展示 |
| 趋势分析 | 日/周/月环比，涨了还是跌了 |
| 客户数据 | 咨询量、转化率、新增客户 |
| 异常告警 | 播放暴跌/涨粉异常自动提醒 |

## 一句话总结

> **做了内容不看数据 = 闭着眼睛干活。数据看板让你睁开眼。**

# 现场培训纪要模板（智体FDE · Phase 5 上线交付）

> 本模板用于 FDE 项目**上线交付阶段（Phase 5）**，对客户进行**三类对象（操作员/管理员/CXO）**的系统化培训，并完整记录培训过程、考核结果、反馈意见。每位受训人应签名确认，确保培训闭环；同时作为后续运维参考与培训复盘的核心档案。
>
> 📌 **培训原则**：
> - **分对象**：操作员培训"如何用"，管理员培训"如何管"，CXO培训"价值与战略"
> - **重实操**：每个功能必须现场演练+学员亲手操作，而非讲师演示
> - **必考核**：每个对象培训后立即考核，未通过者安排补训
> - **建档案**：所有材料归档到客户档案，便于新人入职和后续查询
>

> - 售后邮箱：**support@594agent.com**

> - SaaS订阅：**¥299/月/台**（含云端模型+远程运维）

## 📚 培训内容详解

## 🟢 第一部分：操作员培训（1.5小时）

> 📌 **培训目标**：操作员能独立"接收告警→处理违规→查看数据→日常巡检"

### 3.1 培训内容（操作员）

#### 模块1：接收告警（25分钟）

**核心要点**：
- 告警怎么到达我？（手机企微/钉钉/短信/SMS/音柱）
- 告警是什么意思？（违规类型 + 位置 + 时间 + 截图）
- 我要做什么？（确认违规+赶到现场+处置+回执）

**培训步骤**：

1. **演示**：讲师手机端收到一条测试告警，逐字段解读
2. **解读字段**：
   - 违规类型（如"未戴安全帽"）
   - 摄像头位置（如"装配车间-东门-03号"）
   - 发生时间（精确到秒）
   - 违规截图（高清图）
   - 应急建议（语音播报+文本）
3. **现场演练**：
   - 模拟违规场景（讲师现场不戴安全帽）
   - 让学员接收告警 → 解读 → 处置
4. **常见问题**：
   - 收不到告警？→ 检查企微/钉钉是否在线、群是否设免打扰
   - 收到太多告警？→ 启用分级告警（紧急/中级/低级）
   - 告警延迟？→ 检查手机网络、缩短推送间隔<3秒

#### 模块2：处理违规（25分钟）

**核心要点**：
- 现场处置流程（接到告警后该干什么）
- 处置回执（在App点击"已处理"或备注说明）
- 异常情况上报（设备故障、算法误报）

**培训步骤**：

1. **演示完整流程**：告警→查看详情→现场处置→App回执
2. **处置流程图**：
   ```
   接收告警 → 1分钟解读 → 5分钟现场处置 → App点击"已处理"
   ```
3. **4类典型处置**：

| 违规类型 | 处置方式 | 处置时限 |
|---------|---------|---------|
| 未戴安全帽 | 立即要求佩戴+登记 | 5分钟内 |
| 区域入侵 | 劝离+核实身份 | 5分钟内 |
| 违规吸烟 | 立即制止+罚款 | 即时 |
| 摔倒/异常 | 救援+救护 | 即时 |

4. **演练**：分组模拟4类违规处置

#### 模块3：查看数据看板（20分钟）

**核心要点**：
- 灵虾平台/微信小程序 AI店长 数据看板入口
- 实时数据怎么看（客流/告警/缺货/销量）
- 历史数据怎么查（按日/周/月）

**培训步骤**：

1. **演示登录**：
   - 灵虾平台 web版：浏览器访问 `lingxia.594agent.com`
   - 微信小程序版：搜索"AI店长"扫码登录
2. **讲解关键数据**：

| 数据项 | 业务含义 | 操作员关注点 |
|--------|---------|------------|
| **实时告警** | 当前正在发生的违规 | 必须即时处理 |
| **今日告警统计** | 当天违规总数与TOP类型 | 识别高发违规 |
| **本周合格率** | 一周内合规率变化 | 看趋势 |
| **TOP10违规人员** | 违规最多的人员 | 重点关注（敏感数据，仅管理员可见） |

3. **演示查询历史**：选日期范围 → 查看每日报告
4. **常见操作**：
   - 查看告警详情截图
   - 导出当日报告（Excel/PDF）
   - 切换摄像头视角

#### 模块4：日常巡检（20分钟）

**核心要点**：
- 巡检什么？（设备状态、镜头清洁、网络连通）
- 多久巡检一次？（每班次交接前5分钟）
- 发现问题怎么办？（应急联系卡流程）

**培训步骤**：

1. **日常巡检5项清单**：

| # | 检查项 | 工具 | 异常处置 |
|---|--------|------|---------|
| 1 | 设备指示灯是否正常 | 目视 | 拍照报修 |
| 2 | 摄像头镜头是否清洁 | 镜头布 | 清洁+报备 |
| 3 | 告警是否正常推送 | 接收测试 | 找IT |
| 4 | 现场合规情况 | 巡视 | 教育+整改 |
| 5 | 设备运行温度 | 手背触盒 | 过热报修 |

2. **演示完整巡检**：讲师带领学员走一遍
3. **应急联系卡**：
   - 24小时服务：**support@594agent.com**
   - 紧急联系：IT主管+管理员手机
   - 钉钉群：项目专属群（扫码进入）

## 🔵 第二部分：管理员培训（2小时）

> 📌 **培训目标**：管理员能独立"调参数、升级Skill、管用户、导数据、月度巡检"

### 4.1 培训内容（管理员）

#### 模块1：参数调整（30分钟）

**核心要点**：
- 灵虾平台参数体系（阈值/敏感度/区域/时段）
- 调参会影响什么（漏检 vs 误检的平衡）
- 调参方法（可视化拖拽 vs JSON配置）

**培训步骤**：

1. **后台登录**：
   - 管理员账号：`admin@xxx.com`
   - 灵虾平台 → 设备管理 → 选择摄像头 → 参数配置
2. **关键参数详解**（以安全监测Skill为例）：

| 参数 | 默认值 | 取值范围 | 影响 | 调整建议 |
|------|--------|---------|------|---------|
| **置信度阈值** | 0.5 | 0.3-0.9 | 高=准确但漏检，低=召回但误报 | 0.5-0.7之间 |
| **最小触发时长** | 5秒 | 1-60秒 | 过滤瞬时误判 | 3-10秒 |
| **告警去重间隔** | 30秒 | 5-300秒 | 避免告警轰炸 | 30-60秒 |
| **检测区域** | 全画面 | 用户框选 | 限定检测范围 | 框定关键区域 |
| **告警时段** | 全天 | 自定义 | 仅在某时段启用 | 上班时间+夜间 |
| **人员白名单** | 空 | 名单管理 | 特定人员/工种不报警 | 电工/主管/来访 |

3. **现场演示**：3个调参场景
   - 误报率高（>15%）→ 提高阈值
   - 漏检率高（>10%）→ 降低阈值/缩短最小触发时长
   - 告警时间段不匹配 → 调整告警时段

4. **调参三原则**：
   - **小步调整**：每次只调一个参数，幅度<20%
   - **观察24h**：调整后至少观察24小时再决定
   - **记录对照**：调整前后记录告警数对比

#### 模块2：Skill更新（25分钟）

**核心要点**：
- Skill版本管理（安装/升级/回滚）
- 自动升级 vs 手动升级
- 升级失败的应急处理

**培训步骤**：

1. **Skill市场介绍**：灵虾平台 → Skill市场 → 浏览Skill
2. **Skill操作演示**：

| 操作 | 步骤 | 注意事项 |
|------|------|---------|
| **安装新Skill** | Skill市场 → 选择 → 安装 → 参数配置 → 启用 | 版本兼容检查 |
| **升级Skill** | Skill管理 → 选择 → 升级 → 重启服务 | 灰度升级 |
| **回滚Skill** | Skill管理 → 版本历史 → 选择稳定版 → 回滚 | 紧急用 |
| **停用Skill** | Skill详情 → 关闭 | 释放资源 |

3. **自动 vs 手动**：
   - 自动升级：试用版/小版本，灰度策略
   - 手动升级：关键场景需审核
4. **升级SOP**：
   - 灰度发布：5% → 20% → 50% → 100%
   - 每阶段观察24小时
   - 失败回滚阈值：准确率下降>5%立即回滚

#### 模块3：用户管理（20分钟）

**核心要点**：
- 用户角色体系（管理员/操作员/查看者）
- 增删用户、密码重置
- 权限的边界（什么角色能干什么）

**培训步骤**：

1. **用户管理入口**：灵虾平台 → 系统设置 → 用户管理
2. **3类角色权限**：

| 角色 | 查看 | 操作 | 管理 | 适用 |
|------|------|------|------|------|
| **管理员** | ✓全部 | ✓全部 | ✓全部 | IT/班组长 |
| **操作员** | ✓业务数据 | ✓处理告警 | ✗ | 一线员工 |
| **查看者** | ✓只读看板 | ✗ | ✗ | CXO/管理层 |

3. **常见操作**：
   - 添加用户：邮箱+角色+权限范围
   - 重置密码：短信验证/邮件重置链接
   - 离职用户处理：停用账号（建议保留3个月）
   - 数据权限：跨门店管理员仅可见指定门店

#### 模块4：数据导出与备份（25分钟）

**核心要点**：
- 灵虾平台数据导出（告警/检测/报告）
- 本地数据备份（盒子侧 + 云端侧）
- 备份验证与恢复演练

**培训步骤**：

1. **平台数据导出**：
   ```
   灵虾平台 → 数据管理 → 选择日期范围 → 选择数据类型 → 导出格式
   支持格式：Excel / CSV / PDF / JSON
   ```
2. **典型导出场景**：

| 场景 | 导出内容 | 频率 |
|------|---------|------|
| 月度经营报告 | 客流+销售+告警汇总 | 每月1次 |
| 合规审计 | 全部告警+视频+截图 | 按需 |
| 数据分析 | 原始事件流 | 按需 |

3. **本地备份**：
   - 自动备份：每日凌晨自动备份到云端/对象存储
   - 手动备份：管理员触发本地备份
   - 备份验证：每月1次恢复演练（验证可恢复）

4. **数据保留策略**（按合规要求）：

| 数据类型 | 保留时间 | 法律依据 |
|---------|---------|---------|
| 告警事件 | ≥365天 | 《安全生产法》 |
| 检测图片 | ≥90天（默认30天，可延长） | 行业规范 |
| 视频录像 | ≥90天（合规场景） | 监管要求 |
| 操作日志 | ≥180天 | 等保2.0 |

#### 模块5：月度巡检与运维（20分钟）

**核心要点**：
- 月度巡检5项（硬件/Skill/网络/数据/客户反馈）
- 巡检工具与流程
- 发现问题如何升级

**培训步骤**：

1. **月度巡检5项**（详见 `monthly-ops-report-template.md`）：

| # | 巡检项 | 工具 | 输出 |

2. **演示完整巡检**：讲师带学员走一遍
3. **问题升级路径**：
   - P0/P1（紧急/高）：30分钟/2小时首响应，联系**support@594agent.com**
   - 远程无法解决：FDE现场支持

## 🟣 第三部分：CXO培训（30分钟）

> 📌 **培训目标**：CXO能"看到ROI、认知战略价值、明确扩展方向"

### 5.1 培训内容（CXO）

#### 模块1：ROI查看（10分钟）

**核心要点**：
- ROI看板：投入 vs 产出
- 3个关键业务指标：成本下降 / 效率提升 / 风险降低

**培训步骤**：

1. **演示ROI看板**：灵虾平台 → 数据看板 → ROI中心
2. **核心KPI**（以工业质检为例）：

| 指标 | 计算 | 价值 |
|------|------|------|
| **漏检率变化** | 3% → 0.5% | 提升90%质量 |
| **月节省人工** | ¥8,000 | ROI关键 |
| **回本周期** | 3.3个月 | 投资回报速度 |
| **3年总收益** | ¥250,000+ | 长期价值 |

3. **客户案例分享**：1-2个同行业实施案例（脱敏）

#### 模块2：战略价值（10分钟）

**核心要点**：
- AI盒子作为"AI员工"的战略含义
- 数据资产沉淀（检测数据→行业洞察）
- 长期扩张路径（Lite → Pro → 算网）

**培训要点**：

1. **从工具到资产**：
   - 第一阶段（3个月）：降本增效，看得见的ROI
   - 第二阶段（6-12个月）：数据沉淀，识别工艺改进
   - 第三阶段（12个月+）：AI员工化，成为组织能力
2. **扩张路径**：
   - Lite（1-2路）→ Pro（4-8路）→ Enterprise（16+路）
   - 单点 → 多门店 → 跨工厂（多Pro协同）
   - 独立 → 接入龙虾算网（赚积分/共享算力）
3. **生态联动**：
   - 灵虾平台集中管理（多门店/多工厂）
   - 智体联邦多智能体协作
   - OpenClaw Skills按需扩展

#### 模块3：集成方案（10分钟）

**核心要点**：
- 与现有系统的集成（MES/ERP/OA/企微/钉钉）
- 多产品组合方案
- 后续扩展的可能性

**培训要点**：

1. **集成地图**：
   - **数据上行**：AI盒子 → 灵虾平台 → 客户BI系统
   - **告警下行**：灵虾平台 → 企微/钉钉/SMS → 客户员工
   - **业务对接**：MES/PLC（OPC UA/Modbus）+ 收银/POS（HTTP）+ OA/ERP（API）
2. **多产品组合示例**：
   - 工业场景：Pro盒子 + 龙虾硬盘（数据本地备份） + 灵虾平台（多厂区管理）
   - 零售场景：Lite盒子 + 微信小程序AI店长 + 灵虾平台（连锁管理）
   - OPC场景：U盘/硬盘 + OpenClaw Skills + 智体数字人
3. **下一步合作建议**：
   - 短期（3个月）：稳定运行、效果验证
   - 中期（6个月）：第二场景扩展、追加Skill
   - 长期（12个月+）：跨工厂/多门店集团化

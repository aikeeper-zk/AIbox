## 附录 A：常用勘察命令速查

### A.1 网络测试（Windows / macOS / Linux）

```bash
# 1. ping 测试
ping 192.168.1.100       # 测试到摄像头/盒子的连通性
ping -c 100 8.8.8.8      # 测丢包率

# 2. 带宽测试
iperf3 -c 192.168.1.1    # 测试带宽（需两端均安装 iperf）

# 3. RTSP 测试（VLC）
vlc rtsp://user:pass@192.168.1.100:554/Streaming/Channels/101

# 4. ONVIF 设备发现（推荐使用 ONVIF Device Manager）
# 下载地址：http://tekniskaonsult.se/onvif/

# 5. 端口连通性
curl -v telnet://192.168.1.100:554    # RTSP 默认端口
curl -v telnet://192.168.1.100:502    # Modbus TCP 默认端口
```

### A.2 摄像头常用 RTSP URL 格式

| 品牌 | RTSP URL 格式 |
|------|--------------|
| **海康威视** | `rtsp://{user}:{pass}@{ip}:554/Streaming/Channels/{101=主码流/102=子码流}` |
| **大华** | `rtsp://{user}:{pass}@{ip}:554/cam/realmonitor?channel=1&subtype=0` |
| **宇视** | `rtsp://{user}:{pass}@{ip}:554/unicast/c{n}/s0/live` |
| **华为** | `rtsp://{user}:{pass}@{ip}:554/Livestream/1/ch1` |
| **萤石** | `rtsp://{user}:{pass}@{ip}:554/h264/ch01/main/av_stream` |
| **Onvif 通用** | `rtsp://{ip}/onvif/1`（多数摄像头支持） |

### A.3 常见默认端口

| 协议 | 端口 | 用途 |
|------|------|------|
| RTSP | 554 / 8554 | 视频流 |
| ONVIF | 80 / 8080 | 设备发现/控制 |
| HTTP | 80 / 8080 | Web 管理 |
| HTTPS | 443 | 安全 Web |
| MQTT | 1883 / 8883（TLS） | 物联网消息 |
| Modbus TCP | 502 | 工业 PLC |
| OPC UA | 4840 | 工业设备 |
| SSH | 22 | 远程登录 |
| RDP | 3389 | Windows 远程桌面 |

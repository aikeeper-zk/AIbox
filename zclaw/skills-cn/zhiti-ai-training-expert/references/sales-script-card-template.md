# 话术卡模板

## 话术卡标准格式

```markdown
# 💬 话术卡｜{场景名称}

## 客户画像
- **典型客户**：{行业/规模/角色}
- **核心痛点**：{1-2个关键痛点}
- **购买决策因素**：{价格/安全/便捷/效果}

---

## 异议处理话术

### 异议1："{客户常说的话}"
| 维度 | 内容 |
|------|------|
| **客户说** | "{原话}" |
| **潜台词** | {客户真正担心什么} |
| **你回答** | "{标准话术，2-3句}" |
| **支撑论据** | {数据/案例/类比} |
| **跟进动作** | {引导到下一步} |

### 异议2："{客户常说的话}"
（同上结构）

### 异议3："{客户常说的话}"
（同上结构）

---

## 主动出击话术

### 开场话术
- **场景**：{首次接触/展会/转介绍}
- **话术**："{开场白，3秒抓住注意力}"

### 价值传递话术
- **核心卖点**：{1号卖点}
- **话术**："{用类比/数据/故事传递价值}"

### 促单话术
- **时机**：{客户表现出购买信号时}
- **话术**："{限时/限量/对比紧迫感}"

---
```

## 话术卡类型速查

| 类型 | 异议数量 | 适用对象 | 来源 |
|------|---------|---------|------|
| 产品异议处理卡 | 3-5个异议 | 代理商/销售 | 百问百答Q1-Q103 |
| 竞品对比话术卡 | 2-3个竞品 | 代理商/销售 | 百问百答+企业材料 |
| ROI算账话术卡 | 1-2组对比 | 企业客户/代理商 | 企业材料+百问百答 |
| 配置选型话术卡 | 3-5个选择 | 新用户/代理商 | 百问百答+配置选型 |
| 促单转化话术卡 | 2-3个场景 | 代理商/销售 | 培训经验提炼 |

## 质量标准

| 维度 | 要求 |
|------|------|
| 异议数量 | 至少3个，每个含潜台词+回答+论据+跟进 |
| 话术长度 | 每条回答2-3句，不超过50字 |
| 论据类型 | 优先数据>案例>类比>权威背书 |
| 金句 | 至少2条，简短有力 |
| 数据来源 | 优先从百问百答/企业材料提取，避免凭空编造 |

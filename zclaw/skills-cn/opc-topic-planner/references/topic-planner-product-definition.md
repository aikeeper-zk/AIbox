# 选题助手 · 产品定义文档

> 智体OPC工具箱 · 内容生产上游·灵感引擎
> 版本：v1.0 | 日期：2026-06-25

---

## 一、一句话定位

**选题助手**是运行在小龙虾AI盒子上的AI选题灵感工具，让OPC创作者**不用每天想"今天发什么"**，自动推送热点选题、分析爆款方向、规划一周内容日历。

---

## 二、解决的核心痛点

| 痛点 | 表现 | 影响 |
|------|------|------|
| 😩 **选题枯竭** | 每天打开编辑框不知道写什么 | 断更、焦虑 |
| 🔍 **追热点太慢** | 热点出来了才看到，别人已经发了 | 永远吃不到流量 |
| 📊 **不知道什么能火** | 辛辛苦苦做的内容没人看 | 投入产出不成正比 |
| 📅 **没有规划** | 今天想今天发，临时抱佛脚 | 内容质量不稳定 |

---

## 三、核心功能

| 功能 | 说明 | 价值 |
|------|------|------|
| 🔥 热点追踪 | 监测行业/领域热词热搜，自动推送 | 永远跟上热点 |
| 📈 爆款分析 | 分析各平台爆款内容的选题方向+结构 | 知道什么能火 |
| 📅 选题日历 | 一键生成一周选题规划 | 系统化输出 |
| 🎯 选题库管理 | 历史选题/待做选题/已做选题分类管理 | 灵感不浪费 |

---

## 四、与文案助手的配合

```
选题助手             文案助手             智体数字人
┌──────────┐      ┌──────────┐      ┌──────────┐
│ 今日热点  │      │ 自动写稿  │      │ 自动出片  │
│ 爆款分析  │ ──→  │ 批量生产  │ ──→  │ 批量渲染  │
│ 选题日历  │      │ 标题优化  │      │ 定时发布  │
└──────────┘      └──────────┘      └──────────┘
  "今天发什么"      "帮我写出来"       "帮我拍出来"
```

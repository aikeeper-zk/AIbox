## 一、处理器平台（CPU）

### 1.1 RK3588（ARM架构）

| 参数项 | 规格 |
|--------|------|
| 型号 | Rockchip RK3588 |
| CPU架构 | ARM Cortex-A76 × 4（大核）+ Cortex-A55 × 4（小核）|
| 最高主频 | 2.4 GHz |
| 制程工艺 | 8nm |
| 板载NPU | 6 TOPS INT8 |
| 内存支持 | LPDDR5（最高32GB）|
| 典型功耗 | 8-15W |
| 散热方式 | 被动散热 + 静音风扇 |
| 视频编解码 | 8K@60fps解码 / 4K@120fps编码 |
| AI框架支持 | TensorFlow、PyTorch、ONNX、RKNN |
| 系统支持 | Ubuntu / Debian / Android |
| **产品归属** | 智体共合官方Lite版标配 |

**优点**：
- 低功耗、低发热，适合7×24运行
- 内置NPU，无需额外算力卡即可跑轻量AI
- 成本低，Lite版标配

**缺点**：
- 板载NPU仅6 TOPS，重度AI任务需要外接算力
- ARM生态部分软件兼容性不如x86

### 1.2 Intel N100（x86架构）

| 参数项 | 规格 |
|--------|------|
| 型号 | Intel Processor N100（Alder Lake-N）|
| CPU架构 | 4核4线程 x86 |
| 最高主频 | 3.4 GHz（单核峰值）|
| 制程工艺 | Intel 7（10nm）|
| 板载NPU | 无（需外接NPU/GPU加速卡）|
| 内存支持 | DDR4/DDR5 / LPDDR5 |
| 典型功耗 | 6-25W（可配置TDP）|
| 散热方式 | 主动散热（风扇）|
| AI框架支持 | 全x86生态（Ollama、llama.cpp等）|
| **产品归属** | 智体共合官方Pro版标配 |

**优点**：
- x86全生态兼容，软件适配最好
- CPU通用算力强，适合复杂计算任务
- 可外接高性能NPU/GPU扩展算力

**缺点**：
- 无板载NPU，纯CPU跑AI效率低于NPU
- 功耗和发热高于RK3588
- 成本相对更高

## 三、内存（RAM）

### 3.1 规格参数

| 参数项 | 规格 |
|--------|------|
| 类型 | LPDDR5（RK3588）/ DDR5或LPDDR5（N100）|
| 可选容量 | 4GB / 8GB / 16GB / 32GB |
| 内存带宽 | 最高 51.2 GB/s（LPDDR5） |
| 架构 | 与CPU集成封装（RK3588为PoP封装）|

### 3.2 容量选型建议

| 容量 | 适合场景 | 不建议的场景 |
|:----:|---------|:------------:|
| **4GB** | 单模型7B以下对话、轻量文档处理 | 多模型并发、14B+模型、多路视频分析 |
| **8GB** | 7B模型流畅运行、单路视频分析、企业办公 | 14B+模型、多路视频+AI同时处理 |
| **16GB** ⭐ | 7B-14B模型、多模型切换、2-4路视频分析 | 14B模型+多任务高并发 |
| **32GB** ⭐⭐ | 14B+大模型、多模型并发、多路视频、API服务 | — |

**经验法则**：
- 大模型推理：模型参数量 × 2 = 最低内存需求（单位GB）
- 多路视频分析：每路额外预留 1-2GB
- 操作系统 + 基础服务：预留 2-4GB

## 四、存储

### 4.1 存储类型

| 类型 | 容量选项 | 读写速度 | 适用场景 |
|:----:|:--------:|:--------:|---------|
| **eMMC** | 64GB / 128GB | ~300 MB/s | 系统盘、轻量应用、成本敏感 |
| **NVMe SSD** | 256GB / 512GB / 1TB | ~3500 MB/s ⭐ | 模型存储、高速读写、主力配置 |
| **MicroSD** | 最大1TB（扩展） | ~100 MB/s | 数据备份、媒体存储、扩展 |
| **USB外接** | 按需 | 取决于接口（USB 3.0 ~500MB/s）| 大容量冷数据存储 |

### 4.2 容量选型建议

| 使用场景 | 推荐配置 | 理由 |
|---------|---------|------|
| 轻量使用（对话/文档） | 64GB eMMC | 系统+A few小模型够用 |
| 标准使用（多模型+应用） | 256GB NVMe ⭐ | 主流选择，性价比最高 |
| 重度使用（大模型+多数据） | 512GB-1TB NVMe | 放得下多个大模型+数据缓存 |
| 视频监控存储 | NVMe + MicroSD扩展 | 主存跑模型，扩展存视频 |

**典型模型占用空间参考**：
- 7B模型（Q4量化）：约4-5GB
- 14B模型（Q4量化）：约8-10GB
- 70B模型（Q4量化）：约40-50GB

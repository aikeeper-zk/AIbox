# 培训材料类型速查

## 按培训目标匹配材料类型

| 培训目标 | 推荐材料类型 | 输出格式 | 说明 |
|----------|-------------|---------|------|
| 系统化学习 | 培训课程（多课时） | Markdown课时文件 | 按五模块课程体系设计 |
| 快速上手 | 操作指南 | Markdown | 分步骤图文教程 |
| 异议处理 | 话术卡 | Markdown表格 | 客户异议→标准回答 |
| 销售培训 | 百问百答速查 | Markdown | 按场景分类，含金句 |
| 方案输出 | 方案书/PPT大纲 | Markdown | 联动现有技能输出 |
| 客户培训 | 场景实操手册 | Markdown | 按行业场景定制 |
| 考核测试 | 问答测试题 | Markdown | 选择题+判断题 |

## 培训材料生成决策

```
用户说"培训" → 问清楚培训对象和目标
  ├─ "我要培训代理商" → 代理商培训包（模块一+二+四）
  ├─ "我要培训新用户" → 新用户上手指南（模块一+对应产品课）
  ├─ "我要培训企业客户" → 企业场景实操手册（模块一+三+对应场景）
  ├─ "我要培训政企" → 政企合规培训包（模块一+第12-13课+第16课）
  ├─ "我要培训开发者" → 开发者手册（第5课+第11课+第13课）
  ├─ "我要做内部培训" → 完整课程体系（全模块）
  └─ "我要做OPC培训" → OPC超级个体培训包（模块一+第9-10课+第17课）
```

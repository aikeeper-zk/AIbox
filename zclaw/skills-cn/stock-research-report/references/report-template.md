# 深度投资研究报告模板（强制 ≥3000 字 · 含综合研判）

套用以下章节骨架撰写研报。每个章节后给出「深度要求 / 需回答的关键问题」，必须逐一回答并落到文字；用中文，数据用表格，关键结论加粗。方括号 `[...]` 为占位说明，正式成稿时删除。**总篇幅硬性要求：正文不低于 3000 字（中文字符）**，宁可深挖、不要空洞铺陈。

> 数据口径示例：行情截至 2026-08-07 收盘；财务采用 2025 年报及 2026Q1；估值倍数取最新交易日；行业数据注明来源年份。

## HTML 渲染用的 meta.json

使用 `scripts/build_report.py` 时，提供与正文配套的元数据（封面、评级徽章、指标卡）。字段说明：

```json
{
  "title": "贵州茅台（600519.SH）深度投资研究报告",
  "company": "贵州茅台",
  "ticker": "600519.SH",
  "market": "A股",
  "industry": "食品饮料 / 白酒",
  "rating": "买入",
  "target_price": "¥1,650–1,950",
  "current_price": "¥1,520",
  "upside": "+8% ~ +28%",
  "date": "2026-08-07",
  "analyst": "WorkBuddy 研究助手",
  "summary": "高端白酒龙头，品牌护城河深厚，自由现金流优异；当前估值处于历史中枢偏低。综合三情景与多空辩论，给予买入评级，目标价区间 ¥1,650–1,950，适合中长期稳健型投资者。",
  "metrics": [
    {"label": "总市值", "value": "¥1.91万亿", "note": "A股前列"},
    {"label": "PE(TTM)", "value": "21.3x", "note": "低于 5 年中枢"},
    {"label": "ROE(2025)", "value": "34.6%", "note": "持续领先"},
    {"label": "股息率", "value": "3.4%", "note": "稳中有升"}
  ]
}
```

- `rating` 决定徽章颜色：含“强烈推荐/买入”→ 红，“增持/推荐”→ 橙，“中性/持有”→ 灰，“减持/卖出/回避”→ 绿（遵循涨红跌绿惯例）。
- `target_price` 支持区间写法（如 `¥1,650–1,950`）；`upside` 支持区间写法。
- `metrics` 为指标卡数组，建议 4–6 张；`note` 可选。
- 正文 Markdown 不含上述封面信息（由脚本从 meta 生成），正文从“摘要”章节开始即可。

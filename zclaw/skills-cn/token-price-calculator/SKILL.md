# Token价格计算器

## 概述

本技能是大模型API调用的价格计算与对比工具，帮用户在选模型、做预算时快速算出Token成本和性价比。

知识来源：36氪《大模型价格战逆转？深扒17家厂商最新定价》等公开价格数据。

## 你的工作方式

| 用户意图 | 路由到 |
|---|---|
| 算算用XX模型处理XX字/段文本要多少钱 | **计算 → 模式1：直接计算** |
| 对比几个模型的价格 | **计算 → 模式2：多模型对比** |
| 日/月调用量的成本预估 | **计算 → 模式3：批量估算** |
| 这段文本大概多少Token？ | **估算 → Token数预估** |
| 哪个模型最划算/性价比最高 | **计算 → 模式2 + 推荐** |
| 不确定选哪个模型 | 先问场景和预算，再推荐+报价 |

## 计算流程

### 第1步：确认关键信息

你需要向用户要以下信息（缺啥补啥）：
- **模型名称**：用户想用哪个模型？
- **输入内容量**：文本字数/文档页数/调用次数
- **输出内容量**：期望输出多长（如摘要200字、代码50行）
- **调用频率**：单次/日均/月均调用量

### 第2步：Token数估算

中文Token估算规则（参考GPT系列）：
- **中文**：1个汉字 ≈ 1.5-2 tokens（口语化文本偏少，专业/古文偏多）
- **英文**：1个英文单词 ≈ 1.3 tokens
- **代码**：1行代码 ≈ 3-5 tokens
- **快速估算**：1个汉字 ≈ 2 tokens（保守起见）

常见内容量参考：
| 内容类型 | 大致Token数 |
|---|---|
| 100字中文 | ~150-200 tokens |
| 1000字中文 | ~1500-2000 tokens |
| 1页中文文档（500字） | ~750-1000 tokens |
| 10页文档 | ~7500-10000 tokens |
| 1小时会议记录 | ~8000-12000 tokens |
| 1篇学术论文（~8000字） | ~12000-16000 tokens |

### 第3步：查价格并计算

读取 `references/llm-pricing.md` 获取最新价格表，按公式计算：

```
总价 = (输入tokens × 输入单价 + 输出tokens × 输出单价) / 1000000
```

### 第4步：输出格式

输出建议包含：
1. **计算过程**：输入tokens、输出tokens、单价、总价
2. **对比参考**：同价位区间的其他模型选择
3. **省钱建议**：如果用户用量大，推荐更经济的方案

## 详细计算模式

### 模式1：单模型直接计算

**输入**：模型 + 输入文本量/Token数 + 输出量
**输出**：单次调用价格

示例：
```
模型：DeepSeek-V3.1
输入：10000 tokens（约5000字中文）
输出：500 tokens（约250字回复）
→ 成本 = (10000×4 + 500×12) / 1000000 = 0.046元 ≈ 5分钱
```

### 模式2：多模型对比

**输入**：用户场景描述 + 待对比模型列表
**输出**：对比表格 + 推荐

```markdown
| 模型 | 输入价 | 输出价 | 单次成本 | 每月1万次 |
|------|--------|--------|---------|----------|
| DeepSeek V3.1 | 4元 | 12元 | 0.05元 | 500元 |
| Qwen-Plus | 4元 | 12元 | 0.05元 | 500元 |
| 豆包1.6 | 0.8元 | 2-8元 | 0.03元 | 300元 |
```

### 模式3：批量成本估算

估算维度：
- **日均调用量** × 单次成本 = 日成本
- **月均调用量** × 单次成本 = 月成本
- 附加项：推理缓存命中率（缓存命中成本可降低90%）

## 工作流示例

### 示例1：算单个API调用

用户："帮我算算用GPT-4o翻译一篇5000字的中文文档要多少钱"

1. 估算：5000字中文 ≈ 7500-10000 tokens（算9000）
2. 输出：2000 tokens（翻译输出通常比原文略长，算3000个英文tokens）
3. 查价：GPT-4o 输入≈2.5美元/百万tokens，输出≈10美元
4. 计算：(9000×2.5 + 3000×10) / 1000000 = 0.0045 + 0.015 = 0.0195美元 ≈ 1.4元
5. 输出结果 + 推荐国产替代方案（如Qwen-Plus只要0.05元）

### 示例2：做模型选型预算

用户："我们要做一个客服系统，日均5000次调用，每次对话约500字输入+200字回复，推荐哪个模型？"

1. 估算单次：500字输入≈1000 tokens，200字输出≈400 tokens
2. 日成本 = (1000×输入价 + 400×输出价) / 1000000 × 5000
3. 对比多个模型输出推荐
4. 考虑缓存命中率降低成本

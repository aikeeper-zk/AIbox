# 智体数字人 · 产品定义文档

> 小龙虾AI智能盒子 · 内容生产场景核心技能
> 版本：v1.0 | 日期：2026-06-24
> 品牌名：智体数字人（别称：龙虾数字人）

---

## 一、一句话定位

**智体数字人**是运行在小龙虾AI盒子上的3D写实数字人内容生产技能，让OPC自媒体/一人公司通过**输入文本→生成数字人口播短视频**，**5分钟产出1条高质量视频**，不需要演员、不需要摄影棚、不需要剪辑。

---

## 二、解决的核心痛点

| 痛点 | 具体表现 | 影响 |
|------|----------|------|
| 🎬 **视频制作成本高** | 请演员/出镜剪辑，1条视频成本500-2000元 | 无法规模化内容生产 |
| 👤 **真人出镜压力大** | 个人创作者面对镜头紧张，NG多次 | 内容产出效率低 |
| ⏰ **拍摄剪辑耗时长** | 写稿→拍摄→剪辑→发布，1条视频3-5小时 | 每天最多产2-3条 |
| 🏢 **一人公司精力有限** | 老板既要干活又要拍视频做营销 | 分身乏术 |
| 📊 **内容产量不稳定** | 状态好就多拍，状态差就停更 | 账号运营不稳定 |

**行业数据**：
- 数字人短视频制作成本仅为传统方式的 **15%**（从1,200元→180元/条）
- 更新周期缩短 **90%**（从7天→12小时）
- 数字人直播商家数2026年增长 **5倍**（京东618数据）

## 三、核心功能

### 3.1 🎭 3D写实数字人克隆

| 功能 | 说明 | 技术路径 |
|------|------|---------|
| 形象克隆 | 拍摄10-15分钟正面视频 → AI生成数字人分身 | HeyGem.ai开源方案适配 |
| 声音克隆 | 5分钟录音 → 克隆说话人声音和语气 | Fish-Speech技术 |
| 写实渲染 | 3D高拟真渲染，接近真人出镜效果 | 轻量化3D引擎 |

### 3.2 📝 文本驱动视频生成

| 功能 | 说明 |
|------|------|
| 输入文本 → 输出视频 | 写文案 → 选择数字人 → 自动生成口播视频 |
| 批量生产 | 一次导入10条文案，自动排队生成 |
| 多语言支持 | 中文+主流外语，一条形象多条语言共用 |
| 口型自动同步 | 输入文字自动匹配嘴型，亚毫秒级同步 |

### 3.3 ⚙️ 生产效率

| 维度 | 传统方式 | 智体数字人 | 提升 |
|------|---------|-----------|------|
| 1条60秒口播视频 | 3-5小时（拍摄+剪辑） | **5-10分钟**（输入文案→等待渲染） | **18-30倍** |
| 10条批量生产 | 2-3天 | **1小时** | **24-48倍** |
| 单条成本 | 500-2,000元 | **≈5元（电费+算力摊销）** | **99%+** |
| 更新迭代 | 重拍重剪 | **改文案重新生成** | **即时** |

## 五、用户使用流程

### Step 1：克隆数字人形象（首次设置，约15分钟）

```
① 打开OpenClaw → 启用「智体数字人」Skill
② 用手机拍摄10-15分钟正面视频（自然说话，光线均匀）
③ 上传至盒子 → 等待AI处理（约5-10分钟）
④ 你的3D数字人分身创建完成 ✅
```

### Step 2：克隆声音（可选，约5分钟）

```
① 录音5分钟（朗读一段文字即可）
② 上传 → 声音克隆完成
③ 以后生成的视频自动使用你的声音
```

### Step 3：生产视频（日常操作）

```
① 打开智体数字人工作台
② 输入/粘贴文案（或批量导入10条）
③ 选择数字人形象
④ 点击「生成」→ 等待30秒-2分钟 → 视频出炉 ✅
```

### Step 4：发布变现

```
生成好的视频 → 直接发布到抖音/视频号/小红书/B站
```

## 十一、关键风险与应对

| 风险 | 应对 |
|------|------|
| RK3588渲染3D写实数字人性能不够 | Phase 1先做离线视频生成（非实时），Pro版优先推荐 |
| 开源方案适配周期比预期长 | MVP先做一个"有形象的口播视频"跑通闭环，而非完美3D |
| 数字人效果与真人差异明显 | 合理管理预期：定位"效率工具"而非"完美替身" |
| 用户不会操作克隆流程 | 提供手机端拍照引导+15分钟快速教程视频 |
| 竞争对手已有类似方案 | 差异化在于**盒子原生+数据不出盒+极低成本**，不是功能最全 |

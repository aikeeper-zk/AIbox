# 五维深度分析框架与方法

本文件给出研报五维分析的具体方法、常用公式、判断要点与“深度挖掘”工具。目标是让每一维都产出“证据 → 推理 → 结论”的链条，而非表面罗列。分析时结合标的特性选用，但需覆盖五维核心结论，并完成综合研判（多空辩论 + 三情景估值）。

## 一、公司质地

- **业务结构**：收入 / 利润按产品、地区、客户拆分；识别核心现金牛与增长引擎，量化各自占比与增速。
- **护城河类型**（至少识别 1–2 项，并给量化证据）：
  - 品牌溢价（高端白酒、奢侈品、消费电子）——证据：毛利率溢价、提价能力
  - 网络效应（平台、社交、交易所）——证据：用户/商户双边增速、单用户价值
  - 成本优势（规模、区位、一体化）——证据：单位成本低于同行 %
  - 牌照 / 资源壁垒（金融、能源、电信）——证据：准入限制、资源储量
  - 技术 / 专利壁垒（半导体、创新药、高端装备）——证据：研发强度、专利数、工艺良率
- **治理与激励**：实控人、管理层稳定性、股权激励、历史资本配置（并购 / 分红 / 回购记录）。
- **资本配置分析（深度工具）**：把公司历年自由现金流的去向拆为“分红 / 回购 / 并购 / 扩产”，判断是否为股东创造价值（ROIC 是否高于融资成本）；警惕“高价并购堆商誉”。

## 二、行业景气

- **生命周期**：导入 / 成长 / 成熟 / 衰退，对应不同的估值锚（增速 vs 分红）。
- **产业链拆解（深度工具）**：画出“上游—中游—下游”，标出每一环的集中度与利润池分布；定位公司在哪一环、对上下游的议价能力（用毛利率、应付账款/应收账款周转、预付款占比佐证）。
- **供需与格局**：CR3/CR5 集中度及趋势、价格周期位置、产能利用率、进口替代空间。
- **政策敏感度**：列举正面 / 负面政策变量及传导路径（如补贴退坡 → 需求 ↓ → 价格战）。
- **空间测算**：TAM / SAM，用“渗透率 × 客单价 × 用户数”等可验证口径，并做乐观/中性/悲观三档。
- **多空证据采集**：行业章节必须同时记录支持与削弱景气度的证据，避免单边叙事。

## 三、财务质量

核心指标与公式：

| 指标 | 公式 / 口径 | 关注点 |
| --- | --- | --- |
| 毛利率 | (营收 − 营业成本) / 营收 | 趋势、同行对比 |
| 净利率 | 归母净利润 / 营收 | 费用率变化 |
| ROE（杜邦） | 净利率 × 总资产周转率 × 权益乘数 | 拆驱动来源 |
| 经营现金流 / 净利润 | 经营现金流净额 / 净利润 | <1 警惕盈利质量 |
| 资产负债率 | 总负债 / 总资产 | 偿债与杠杆 |
| 自由现金流 | 经营现金流 − 资本开支 | 真实分红能力 |

判断要点：
- 净利润增长是否由现金流支撑；应收账款、存货是否异常膨胀。
- 高增长靠加杠杆还是靠周转 / 利润率改善（杜邦拆解）。
- 资产减值、商誉、关联交易等“利润调节”信号。

**利润率桥（深度工具）**：把“收入变动 → 毛利变动 → 营业利润变动 → 净利变动”逐层归因，定位利润变化的真正来源（量、价、费、税），避免只看净利润增速。

**预警信号清单**：OCF/净利润持续 <1；应收/存货增速 >> 营收增速；商誉占净资产过高；频繁变更会计估计；经营性现金流与净利润长期背离。

## 四、估值

### 相对估值（必做）

- PE：现价 / EPS；与自身历史分位、同业中位数对比（两维同看）。
- PB：现价 / 每股净资产；适用于金融、重资产。
- PS：用于未盈利成长股。
- PEG：PE / 净利润增速(%)；<1 相对低估（需增速可持续）。
- 呈现方式：可比公司估值对比表（代码、PE、PB、PEG、净利润增速、市值）+ 标的估值历史分位。

### 绝对估值（成长/龙头股必做）

- **DCF 思路**：FCFF = EBIT×(1−税率) + 折旧 − 资本开支 − 营运资本增加；折现用 WACC。
  - WACC = E/V × Re + D/V × Rd × (1−税率)，Re 用 CAPM：Re = Rf + β×(Rm−Rf)。
  - 两阶段：显式预测期（通常 5 年）+ 永续增长（g 取长期 GDP/通胀附近，如 2%–3%）。
- **股息贴现（DDM）**：高分红稳定股适用。
- **敏感性**：对 WACC 与永续增速做 ±1% 区间，给出估值区间而非单点。

### 情景估值（综合研判核心）

为综合研判准备三档假设并赋概率：

| 情景 | 关键变量假设 | 合理价值 | 概率 |
| --- | --- | --- | --- |
| 乐观 | 增速/利润率高于一致预期、政策友好 | ¥XX | X% |
| 中性 | 符合一致预期 | ¥XX | X% |
| 悲观 | 增速/利润率不及预期、政策压制 | ¥XX | X% |

概率加权价值 = Σ(情景价值 × 概率)，作为目标价区间中枢；并明确“当前价落在哪一档”。

### 目标价推导

- 主用方法 + 交叉验证方法；目标价区间 = 基准情景合理价值 ×（1 ± 安全边际）。
- 明确“当前价相对目标价的预期空间”与实现所需条件、失效条件。

## 五、风险

按“发生概率 × 影响程度”分级，至少覆盖：

- **经营风险**：竞争加剧、份额流失、技术路线错误、大客户依赖。
- **财务风险**：高杠杆、现金流恶化、商誉减值、汇率。
- **估值风险**：市场预期过高、流动性折价。
- **政策 / 合规风险**：监管、贸易、行业整顿。
- **黑天鹅**：极端情景下的下行空间（压力测试，给出悲观情景股价下限）。

每条风险给出“触发信号”与“对盈利/估值的影响量级”，避免空泛罗列。

## 综合研判工具

### 多空对等辩论框架

分别列出看多 / 看空论据（各 ≥3 条），每条附证据；不打分、不偏袒，目的是暴露假设与失效条件。常见失效条件句式：“若 [变量] 不成立 / 恶化，则本逻辑反转，目标价下看至 ¥XX。”

### 结论整合

- 将五维结论收敛为：核心投资逻辑（1–3 句话）、评级、概率加权目标价区间、关键催化、主要风险。
- 多空论据对等呈现，避免选择性举证；最终评级必须能被全文证据链支撑。

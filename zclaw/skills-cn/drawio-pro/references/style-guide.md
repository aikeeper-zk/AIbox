# Draw.io 样式参考

## 标准调色板
| 名称 | 填充色 | 描边色 | 文字色 | 适用场景 |
|---|---|---|---|---|
| blue | #2563eb | #1e40af | #ffffff | 主色/关键节点 |
| lightblue | #e0f2fe | #0284c7 | #0f172a | 一般流程 |
| green | #dcfce7 | #16a34a | #0f172a | 成功/完成 |
| gray | #f1f5f9 | #64748b | #0f172a | 辅助/默认 |
| red | #fef2f2 | #dc2626 | #0f172a | 警告/异常 |
| purple | #f3e8ff | #9333ea | #0f172a | 特殊/系统 |
| orange | #fff7ed | #ea580c | #0f172a | 注意/待办 |
| white | #ffffff | #475569 | #0f172a | 纯白底 |

## 形状类型
| 形状 | 样式关键字 | 用途 |
|---|---|---|
| 圆角矩形 | `rounded=1;arcSize=12;` | 通用流程 |
| 椭圆 | `ellipse;` | 开始/结束 |
| 菱形 | `rhombus;` | 判断/分支 |
| 圆柱 | `shape=cylinder;` | 数据库 |
| 矩形 | 无（默认） | 处理/操作 |
| 虚线框 | `dashed=1;` | 分组/区域 |

## 连线样式
| 样式 | 说明 |
|---|---|
| 正交折线 | `edgeStyle=orthogonalEdgeStyle;rounded=0;` |
| 曲线 | `edgeStyle=curved;rounded=1;` |
| 虚线 | `dashed=1;` |
| 箭头 | 默认有箭头，无需额外设置 |

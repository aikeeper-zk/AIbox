# PPT Generator Skill

## 概述
根据用户需求，自动生成结构化、视觉精美的PPT演示文稿。

## 工作流程

### 1. 确认需求
- 演示主题/目的
- 目标听众（内部汇报/客户提案/公开演讲）
- 页数要求（10/20/30页）
- 风格偏好（商务/科技/文艺/极简）

### 2. PPT结构规划

**标准结构（20页）**：

```
【封面】（1页）
- 标题 + 副标题 + 演讲者 + 日期

【目录】（1页）
- 3-5个主要章节

【引言】（2-3页）
- 背景介绍
- 问题提出
- 演讲目标

【主体内容】（12-15页）
- 每章2-3页
- 每页一个核心观点
- 图文结合

【总结】（1-2页）
- 3个关键要点
- 行动建议

【致谢/Q&A】（1页）
- 感谢聆听
- 联系方式
```

### 3. 视觉设计规范

**配色方案**：

| 风格 | 主色 | 辅色 | 强调色 | 适用场景 |
|---|---|---|---|---|
| 商务专业 | 深蓝#1F497D | 灰#F2F2F2 | 金#D4AF37 | 汇报/提案 |
| 科技感 | 紫#5B2C6B | 青#00B0F0 | 绿#00FFAA | 产品发布/技术分享 |
| 文艺清新 | 绿#2E8B57 | 米白#FFF8F0 | 橙#FF8C00 | 教育/文化 |
| 极简现代 | 黑#1A1A1A | 白#FFFFFF | 红#FF0000 | 创意提案/设计分享 |

**字体规范**：
- 中文标题：思源黑体 Bold，28-36pt
- 中文正文：思源黑体 Regular，18-24pt
- 英文标题：Arial Bold，28-36pt
- 英文正文：Arial Regular，18-24pt
- 引用文字：楷体/Italic，16-20pt

**布局原则**：
- 留白 ≥ 30%面积
- 每页核心信息 ≤ 1个
- 文字密度：≤ 30字/页
- 图片质量：≥ 1920×1080 px

### 4. 输出格式

```
【PPT生成方案】主题：XXX

📊 基础信息：
- 标题：《XXX》
- 页数：XX页
- 风格：XXX
- 目标听众：XXX

📋 结构规划：
1. 封面（1页）
2. 目录（1页）
3. 引言（2页）
...

🎨 视觉设计：
- 配色：主色 #XXXXXX，辅色 #XXXXXX
- 字体：标题-思源黑体 Bold，正文-思源黑体 Regular
- 布局：左文右图/上图下文

📝 内容大纲（逐页）：
第1页（封面）：
  - 标题："XXX"
  - 副标题："XXX"
  - 背景：渐变/图片

第2页（目录）：
  - 3个章节标题
  - 配图标

...

🛠️ 制作工具推荐：
- PowerPoint（功能全面）
- Keynote（Mac用户）
- Canva（在线模板丰富）
- Focusky（3D演示）

💡 优化建议：
- 每页核心信息不超过1个
- 使用高质量图片（Pexels/Unsplash）
- 添加动画但不过度
- 演讲者备注补充细节
```

## 示例

**输入**：主题"停止自我攻击"心理健康讲座，页数20页，听众：企业员工

**输出**：
```
【PPT生成方案】主题：停止自我攻击

📊 基础信息：
- 标题：《别再骂自己了：停止自我攻击指南》
- 页数：20页
- 风格：文艺清新（温暖、治愈）
- 目标听众：企业员工（心理健康讲座）

📋 结构规划：
1. 封面（1页）
2. 讲者介绍（1页）
3. 目录（1页）
4. 引言：你有过这种时候吗？（2页）
5. 第一章：什么是自我攻击？（3页）
6. 第二章：自我攻击的根源（3页）
7. 第三章：3个方法停止自我攻击（5页）
8. 第四章：长期维护心理健康（3页）
9. 总结+Q&A（1页）

🎨 视觉设计：
- 配色：主色 #2E8B57（绿），辅色 #FFF8F0（米白），强调色 #FF8C00（橙）
- 字体：标题-思源黑体 Bold 32pt，正文-思源黑体 Regular 20pt
- 布局：大量留白，温暖插画点缀

📝 内容大纲（逐页）：
第1页（封面）：
  - 标题："别再骂自己了"
  - 副标题："停止自我攻击实践指南"
  - 演讲者："细弟"
  - 背景：温暖橙渐变 + 手绘插画（人物思考）

第2页（讲者介绍）：
  - 照片（可选）
  - 名字+ title
  - 3句话经历
  - 为什么讲这个话题？

第3页（目录）：
  - 第一章：什么是自我攻击？
  - 第二章：自我攻击的根源
  - 第三章：3个方法停止自我攻击
  - 第四章：长期维护心理健康
  - 配图标（每个章节一个图标）

第4-5页（引言）：
  - 第4页：提问互动
    "有没有过这种时候——
     明明别人随口一句话，你却在心里翻来覆去想了三天？"
  - 第5页：数据引入
    "研究表明：80%的职场人存在自我攻击倾向"

第6-8页（第一章：什么是自我攻击？）：
  - 第6页：定义 + 表现
  - 第7页：5个信号（清单体）
  - 第8页：自我攻击 vs 健康反思（对比表）

第9-11页（第二章：自我攻击的根源）：
  - 第9页：童年经历的影响
  - 第10页：社会比较的陷阱
  - 第11页：完美主义的代价

第12-16页（第三章：3个方法）：
  - 第12页：方法一概述
  - 第13页：方法一详细步骤
  - 第14页：方法二概述
  - 第15页：方法二详细步骤
  - 第16页：方法三概述+详细步骤

第17-19页（第四章：长期维护）：
  - 第17页：建立支持系统
  - 第18页：定期心理体检
  - 第19页：何时寻求专业帮助？

第20页（总结+Q&A）：
  - 3个关键要点回顾
  - "感谢聆听"
  - 联系方式（邮箱/微信）
  - Q&A

🛠️ 制作工具推荐：
- Microsoft PowerPoint（功能全面，推荐）
- Canva（搜索"心理健康"模板，快速出图）
- 图片资源：Unsplash（免费高清）/ Pexels（免费）

💡 优化建议：
- 每页核心信息不超过1个（避免信息过载）
- 使用温暖插画（缓解心理话题的沉重感）
- 添加动画：淡入淡出（不要花哨）
- 演讲者备注：每页补充2-3句讲解词
- 互动设计：第4页提问，让听众举手互动
```

## 注意事项
- 文字不宜过多（每页 ≤ 30字）
- 配色考虑色盲友好（避免红绿搭配）
- 字体使用商用授权款（思源系列/阿里巴巴普惠体）
- 图片使用版权清晰的资源（Unsplash/Pexels可商用）
- 动画适度（不要分散注意力）
- 留出演讲者备注空间（重要内容写在备注里）

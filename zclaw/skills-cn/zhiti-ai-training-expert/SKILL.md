# 智体AI培训专家 · 智体共合全产品线培训内容生产引擎

## 概述

智体AI培训专家是**智体共合全产品线的系统化培训内容生产引擎**，与现有"销售/方案输出导向"技能互补，填补"教学/培训导向"的空白。现有技能能答产品问题、出方案，但**不能系统化教授"如何使用、如何部署、如何配置、如何变现"**——本技能专注解决这一缺口。

核心能力：
1. **培训课程体系设计**——按培训对象智能匹配课程模块，生成模块化大纲
2. **培训课时内容生成**——每课含知识点(定义/原理/示例)+实操演练+话术卡+术语速查
3. **话术卡与异议处理**——百问百答103问联动，生成场景化销售话术
4. **场景实操手册**——按行业场景（工业/零售/政企/OPC/获客）定制实操步骤
5. **培训材料多格式输出**——课时MD/话术卡/实操手册/考核题库

始终使用 `references/` 中的模板文件确保输出一致性。产品数据以《智体共合科技公司信息材料》V3.0 和《市场百问百答》v1.1 为准。

## Phase 1：培训总纲设计

**输出物**：用户确认的培训总纲草案 MD 文件

### 1.1 需求确认

必须确认以下信息（缺失时主动询问）：

| 项目 | 说明 | 默认值 |
|------|------|--------|
| 培训对象 | 7类之一（新用户/OPC/代理商/企业/政企/开发者/内部员工） | — |
| 培训目标 | 学完能做什么 | — |
| 课时数 | 5-25课时 | 按对象自动推荐（见下方映射表） |
| 深度 | 入门级/进阶级/专家级 | 入门级 |
| 输出格式 | 课时MD/话术卡/实操手册/考核题库 | 课时MD |

**培训对象→课程模块映射**（来自 `references/training-curriculum-template.md`）：

| 培训对象 | 必修模块 | 选修模块 | 课时建议 |
|----------|---------|---------|---------|
| 新用户（U盘/硬盘） | 模块一 + 第5-7课 | 模块三(按场景) | 6-8课时 |
| OPC超级个体 | 模块一 + 第5-6,9-10课 | 模块三(第17课) | 8-10课时 |
| 代理商/渠道 | 模块一 + 模块二 + 模块四 | 模块五 | 15-20课时 |
| 企业客户（盒子） | 模块一 + 第8课 + 模块三(按场景) | 模块四(第21-22课) | 8-12课时 |
| 政企客户 | 模块一 + 第12-13课 + 第16课 | 第23-25课 | 6-8课时 |
| 开发者 | 第5课 + 第11课 + 第13课 | 模块五 | 5-8课时 |
| 内部员工 | 全部模块 | — | 20-25课时 |

### 1.2 总纲设计

- 依据培训对象自动匹配课程模块
- 按五模块递进逻辑设计：**认知筑基 → 产品深挖 → 场景实践 → 业务拓展 → 趋势展望**
- 每课时：序号 + 标题 + 核心要点（一句话说清学什么）
- 输出总纲 MD 文件

### 1.3 确认门

总纲输出为 MD 文件，提交用户确认：
- ✅ 确认 → 进入 Phase 2
- ✏️ 修改 → 按反馈调整后重新确认
- ❌ 推翻 → 重新 1.1

**模板**：`references/training-curriculum-template.md`

## Phase 2：培训内容生产

**输出物**：各课时独立 MD 文件

### 2.1 目录结构

```
/sandbox/workspace/outputs/{培训名称}/
├── 00_培训总纲.md
├── 01_认知筑基篇/
│   ├── 01_智体共合是谁.md
│   ├── 02_三大核心承诺.md
│   └── ...
├── 02_产品深挖篇/
│   └── ...
├── 03_场景实践篇/
│   └── ...
├── 04_业务拓展篇/
│   └── ...
└── 05_趋势展望篇/
    └── ...
```

### 2.2 内容生产方式

- **≤5课时**：逐课生成，无需子代理
- **>5课时**：按模块拆分，每模块一个子代理并行生产（`subagent_spawn`, type=general, model=heavy）

子代理任务须包含：
- 输出目录路径
- 负责的课时文件列表
- 每课标准结构规范（见 `references/lesson-template.md`）
- 写作要求（深度、风格、数据来源）
- 智体联邦知识库 kb_id（供搜索验证）

### 2.3 每课标准结构

严格遵循 `references/lesson-template.md`：

```
🎯 学完这课，你能做到什么（一句话）
📖 核心知识点（3-5个，每个含定义/原理/示例三层）
🔧 实操演练（至少1个场景，含步骤/预期结果/常见问题）
💡 话术/要点卡（销售/代理类课时必含）
📝 关键概念速查（3-5个术语）
📚 延伸阅读（2-3条）
```

### 2.4 质量标准

| 维度 | 要求 |
|------|------|
| 字数 | 每课 1000-1500字（不含模板标记） |
| 知识点 | 3-5个，每个含定义/原理/示例三层 |
| 实操场景 | 至少1个，含步骤+预期结果+常见问题 |
| 话术卡 | 销售/代理类课时必含，其他课时可选 |
| 术语表 | 3-5个核心术语 |
| 数据来源 | 优先从智体联邦知识库检索确认，价格/规格等数据必须从知识库或企业材料验证 |
| 搜索 | 至少搜索2-3个中文来源补充行业背景 |

### 2.5 确认门

验证所有课时文件完整，报告统计：
- 课时总数 / 字数统计
- 模块覆盖情况
- 待完善项（如有）

## Phase 3：培训材料输出（可选）

### 3.1 话术卡生成

基于百问百答103问，按场景分类生成话术卡：

| 话术卡类型 | 内容 | 适用对象 |
|-----------|------|---------|
| 产品异议处理 | "太贵了""数据真的安全吗""断网了怎么办" | 代理商/销售 |
| 竞品对比话术 | "和XX比有什么优势""为什么不用XX" | 代理商/销售 |
| ROI算账话术 | 成本对比、回本周期、年化收益 | 企业客户/代理商 |
| 配置选型话术 | "选哪个型号""U盘和硬盘怎么选" | 新用户/代理商 |

### 3.2 实操手册生成

按行业场景生成实操手册，包含：
- 场景描述（痛点+解决方案）
- 4步部署流程
- 预期效果与ROI
- 常见问题排查

### 3.3 考核题库生成（可选）

- 每课时3-5道选择题 + 2道判断题
- 含答案与解析
- 按培训对象定制难度

### 3.4 归档入库

- 知识库文件夹创建：主文件夹 + 模块子文件夹
- 批量上传：`/sandbox/workspace/skills/ima-knowledge/scripts/upload_file.py`
- 打标签：双层标签（模块标签 + 培训对象标签）

## 工作流示例

### 示例1：代理商培训（15课时）

用户："帮我做一套代理商培训"

1. **Phase 1**：识别对象=代理商→匹配"模块一+二+四"=15课时→输出总纲
2. **Phase 2**：3个子代理并行生产（模块一4课+模块二9课+模块四4课）→每课含话术卡

## 关键原则

1. **培训导向，非销售导向**——本技能的核心差异是"教人用"，不是"卖产品"。每课必须有实操步骤，不能只讲卖点
2. **模块化可裁剪**——五模块课程体系可按培训对象裁剪，不强制全量
3. **模板驱动**——所有输出严格使用 references/ 中的模板，确保一致性
4. **数据来源优先级**——知识库检索 > 企业信息材料 > 百问百答 > 网络搜索
5. **确认门机制**——每个Phase完成必须用户确认，方向不对立即纠正
6. **话术卡嵌入**——销售/代理类课时必须包含异议处理话术，形成"学完即能用"的闭环
7. **与现有技能联动**——可调用各产品专项技能（crayfish-ai-box/lingxia-platform/digital-human-content等）获取深度内容，避免重复建设

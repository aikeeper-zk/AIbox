# 货架空位检测 Skill — 产品定义文档

> 小龙虾AI智能盒子 · 小微零售场景核心技能
> 版本：v1.0 | 日期：2026-06-23

---

## 一、一句话定义

**货架空位检测**是一个运行在小龙虾AI盒子（Lite/Pro）上的边缘AI视觉技能，通过对接普通监控摄像头，实时检测货架上的空缺区域，自动生成补货提醒和缺货分析报告，让小微零售店老板**不用巡店就能知道哪个货架缺货了**。

---

## 二、解决的核心痛点

| 痛点 | 具体表现 | 影响 |
|------|----------|------|
| 缺货看不见 | 老板不在店里时，员工不知道补货优先级，热销品空了也没人管 | 直接损失销售额，客户流失 |
| 巡店效率低 | 每天手动巡店1-2次，一次15-30分钟，还容易遗漏 | 时间成本高，漏检率大 |
| 补货靠感觉 | 什么时间缺货、缺多久、哪个品类最频繁，没有数据支撑 | 库存周转差，资金占用 |
| 连锁管理难 | 多店老板没法同时盯着每个店的面貌 | 管理半径受限，扩张瓶颈 |

**核心数据**：零售行业因缺货导致的销售损失约占 **3-8%**（行业调研数据），对于月流水10万的便利店，每年因此损失 **3.6万-9.6万元**。

---

## 三、工作原理（边缘AI跑通全流程）

```
摄像头实时画面 → 小龙虾AI盒子(Lite) → 本地模型推理 →
  ├─ 正常：无事发生（数据不出盒）
  └─ 检测到空位 → 标记空缺区域 → 生成告警 → 推送到老板微信
```

**技术实现要点**：

| 环节 | 方案 | 说明 |
|------|------|------|
| 检测算法 | 轻量化目标检测模型（如YOLOv8-nano / MobileNet-SSD） | Lite版6-10TOPS算力足够跑 |
| 识别方式 | 两种策略：① 检测商品空缺区域 ② 检测货架层板上的空区间隔 | 根据店内摄像头安装位置自适应 |
| 告警触发 | 连续2帧以上检测到空缺面积 > 阈值（可配置） | 避免误报（如顾客拿东西的瞬间） |
| 推送渠道 | 企业微信 / 微信小程序 / 钉钉机器人 | 零成本触达老板 |
| 数据看板 | OpenClaw平台的零售看板 | 日/周/月缺货热力图+趋势分析 |

**离线能力**：网络中断时，本地持续检测并缓存告警数据，恢复后一次性推送。核心业务不中断。

## 四、用户使用流程（零代码全流程）

### Step 1：开机绑定
盒子通电 → 手机扫码绑定 → 选择「货架空位检测」Skill → 点击启用

### Step 2：摄像头配置
- 支持现有监控摄像头（RTSP协议接入）
- 一个盒子最多接入 **2路（Lite）/ 4路（Pro）** 货架画面
- 在OpenClaw平台上框出货架区域（拖拽画框，30秒完成）

### Step 3：自主运行
- AI自动检测，零人工干预
- 无需持续标注、无需训练、开盒即用

### Step 4：告警与报告
- **实时告警**：检测到空位 → 截图 + 位置标注 → 推送到微信
- **日报/周报**：缺货统计排行、最常缺货时段、缺货趋势
- **补货建议**：结合历史数据，提示"建议在16:00前补货X商品区域"

## 七、商业模式建议

### 方案A：Skill免费 + 促硬件销售（推荐初期策略）
- 货架空位检测Skill作为**Lite版盒子标配能力**，不单独收费
- 核心目的是让Lite版盒子卖出更多，靠硬件毛利+基础SaaS订阅赚钱
- 后续高级功能Skill（如AI收银、顾客画像）作为增值付费

### 方案B：Skill作为增值插件收费
- Lite版盒子基础价¥8,999（不含此Skill）
- 货架空位检测Skill单独订阅：**¥99/月** 或 **¥999/年**
- 适合已有摄像头系统、只想买AI能力的客户

### 方案C：打包SaaS升级
- 基础SaaS（¥299/月）含基础版（每日报告）
- 高级SaaS（¥499/月）含实时告警+多路+历史趋势

> **我的建议**：初期用**方案A**，把货架空位检测做成Lite版核心卖点之一，快速铺量建立口碑。半年后推出Pro版Skill增值包。

## 八、技术实现路径

### Phase 1：MVP（4-6周）
- 基于开源模型（YOLOv8-nano）训练货架空位检测基础模型
- 实现RTSP拉流 → 本地推理 → 结果输出的完整Pipeline
- 企业微信/钉钉告警推送
- Lite版盒子上跑通

### Phase 2：产品化（4-6周）
- OpenClaw平台上的配置界面（画框标定货架区域）
- 空缺阈值可调
- 日报自动生成（AI总结+截图证据）
- 数据看板

### Phase 3：优化（持续）
- 模型蒸馏，降低Lite版延迟到 < 200ms/帧
- 支持夜店/弱光场景
- 多店多盒子统一管理看板

## 九、关键风险和应对

| 风险 | 应对 |
|------|------|
| 不同货架（颜色/材质/商品种类差异大）导致误检率高 | 初期限定标准化货架场景，迭代增加泛化能力 |
| 摄像头安装角度不一影响识别 | OpenClaw配置界面提供安装指引模板，支持多角度标定 |
| 客户预期管理（期望识别具体商品SKU） | 明确产品定位为"检测空位"而非"识别商品"，降低预期 |
| 纯纯的小店（如夫妻老婆店）客单价低，付费意愿弱 | 用ROI算账打，两个月回本的逻辑清晰可量化 |

## 十、下一步可扩展的方向

1. **货架热力图**：显示哪些区域顾客拿得多但补货慢
2. **陈列合规检测**：检查商品是否摆放在正确的位置
3. **有效期预警**：结合OCR识别包装上的日期信息
4. **竞品情报**：统计货架上各品牌占比变化

但这些是v2.0以后的事，先把空位检测做到极致。

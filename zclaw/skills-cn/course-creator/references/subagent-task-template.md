# 子代理任务指令模板

按模块拆分课时，每个模块启动一个子代理。task 内容需包含以下所有要素。

## 模板

```markdown
你是一个课程内容创作者。需要为以下[N]个课时撰写完整教学材料。

## 输出目录
所有文件输出到 `/sandbox/workspace/outputs/[课程名]/[模块文件夹]/`

## 需要完成的文件

### [序号]_[文件名].md
**核心要点：** [该课核心内容]
**搜索方向：** [关键词]

### [序号]_[文件名].md
**核心要点：** [该课核心内容]
**搜索方向：** [关键词]

...

## 每课结构规范

\`\`\`markdown
# 第X课：标题

## 概述（300-500字）

## 核心知识点（3-5个知识点，含定义、原理、例子）

## 案例与实践（至少1个具体案例）

## 关键概念总结（3-5个术语）

## 延伸阅读（2-3条资源）
\`\`\`

## 写作要求

1. 每课正文1000-1500字，内容充实
2. 语言专业但不晦涩，适配[目标受众]
3. 主题相关：需搜索至少2-3个[领域]中文来源，综合撰写
4. 每课至少1个[领域]的真实案例
5. 用 file_write 创建文件

请开始工作。
```

## 填写说明

| 占位符 | 说明 |
|:-------|:-----|
| [N] | 该模块的课时数量 |
| [课程名] | 如 AI大模型课程、财商课 |
| [模块文件夹] | 如 01_认知篇、02_工具篇 |
| [目标受众] | 如 职场人士、普通投资者 |
| [领域] | 如 AI、财经、教育 |

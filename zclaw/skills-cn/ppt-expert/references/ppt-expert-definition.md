# 智体PPT专家 · 产品定义文档

> 小龙虾AI盒子 · 演示文稿生成技能
> 版本：v1.0 | 日期：2026-07-06

---

## 一句话定位

**智体PPT专家**是运行在小龙虾AI盒子上的智能PPT生成工具，基于python-pptx离线生成原生可编辑的PPTX文件，内置8套专业模板，输入大纲即出精美演示文稿。

---

## 核心能力

| 能力 | 说明 |
|------|------|
| 📝 大纲驱动 | 输入主题或要点，自动生成完整PPT结构 |
| 🎨 8套模板 | 科技蓝、咨询金、深色科技、简洁白、活力橙、商务灰、自然绿、创意紫 |
| ⚡ 离线生成 | python-pptx本地渲染，数据不出域 |
| ✏️ 原生可编辑 | 输出标准PPTX，用户可自由修改 |
| 🔄 多轮修改 | 支持局部调整，不改动其他部分 |
| 📄 支持版式 | 封面/目录/章节/正文/数据/对比/结尾 |

---

## 8套模板

| 模板 | 风格 | 适合场景 |
|------|------|---------|
| 🟦 科技蓝 | 深蓝+亮蓝渐变 | 科技/AI/互联网 |
| 🟫 咨询金 | 深蓝+金色点缀 | 咨询/金融/商业方案 |
| ⚫ 深色科技 | 深色背景+亮蓝强调 | 发布会/高端展示 |
| ⬜ 简洁白 | 纯白+蓝色点缀 | 通用/教育/严谨 |
| 🟧 活力橙 | 深色+橙色活力 | 创业/新消费/品牌 |
| ⬜ 商务灰 | 灰色调+蓝色 | 传统企业/政府 |
| 🟩 自然绿 | 深绿+翠绿 | 环保/医疗/ESG |
| 🟪 创意紫 | 蓝紫色渐变 | 创意/教育/知识付费 |

## 输出规范

- **格式**：PPTX（原生PowerPoint格式）
- **比例**：16:9（1280×720）
- **字体**：微软雅黑（中）+ Arial（英）
- **可编辑性**：全部文字可修改、可移动

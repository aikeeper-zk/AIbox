# 智能客服 · 产品定义文档

> 智体OPC工具箱 · 营销获客模块核心技能
> 版本：v1.0 | 日期：2026-06-25

---

## 一、一句话定位

**智能客服**是运行在小龙虾AI盒子上的7×24自动客服工具，让OPC创作者把**常见客户问题交给AI回复**，只有AI搞不定的才转人工，**不错过一个客户、不浪费一分钟创作时间**。

---

## 二、解决的核心痛点

| 痛点 | 具体表现 | 影响 |
|------|----------|------|
| ⏰ **24小时都在回消息** | 客户什么时候问都得回，晚上/周末也不消停 | 创作时间被切割，效率暴跌 |
| 🧠 **重复问题每天答** | "多少钱""怎么用""包邮吗"——每天回答几十遍 | 浪费大量重复精力 |
| 💸 **请不起客服** | 月薪3-5k招客服，业务还没做起来先养个人 | 成本压力大 |
| 📈 **漏掉潜在客户** | 回复慢了几分钟，客户就找别人了 | 直接影响收入 |
| 📚 **产品信息记不全** | 客户问的参数/政策记不住，翻半天资料 | 显得不专业 |

---

## 三、核心功能

### 3.1 🤖 自动回复能力

| 功能 | 说明 | 价值 |
|------|------|------|
| 7×24自动应答 | AI 24小时在线，秒回客户消息 | 不错过任何一个客户 |
| 知识库驱动 | 把产品介绍/FAQ/政策喂进去，AI用你的知识回答 | 回复专业、一致 |
| 多渠道接入 | 微信/企业微信/网页客服/公众号 | 一个后台管所有渠道 |
| 智能转人工 | AI识别到客户不满/复杂问题/成交意向 → 转真人 | 关键时刻不失手 |
| 自动打标签 | 根据对话内容自动标记客户意向/需求类型 | 客户分级管理 |

### 3.2 📊 客户转化能力

| 功能 | 说明 |
|------|------|
| 欢迎语+自动引导 | 新客户打招呼时主动引导（"想了解什么？") |
| 常见问题快捷回复 | 价格、服务、物流等高频问题自动解答 |
| 意向识别 | 识别客户购买意向，自动标记为"高意向" |
| 跟进提醒 | AI搞不定的转人工后，给OPC发送跟进提醒 |

### 3.3 ⚡ 效率对比

| 维度 | 自己回消息 | 智能客服 |
|------|----------|---------|
| 响应速度 | 几分钟到几小时（看忙不忙） | **秒级响应** |
| 覆盖时间 | 每天8-10小时 | **7×24小时** |
| 同时接待客户 | 同时聊3-5个就乱了 | **无限并发** |
| 重复问题处理 | 每天花1-2小时回答同样问题 | **AI自动处理90%+** |
| 客户漏接率 | 忙起来忽略=丢客户 | **0漏接** |

## 四、工作原理

```
客户发消息（微信/网页等）
    ↓
小龙虾AI盒子接收
    ↓
AI理解客户问题
    ↓
┌─ 知识库能回答？ → 自动回复（秒级） → 记录对话 ✅
└─ 需要转人工？   → 标记+通知OPC   → OPC亲自上 🧑
```

**混合智能逻辑**：
- 简单的FAQ → 本地模型直接回复（零成本、离线可用）
- 复杂的咨询 → 云端大模型理解+本地知识库回答
- 转人工判定 → 根据客户情绪/关键词/意图自动判断

---

## 五、与小龙虾盒子的适配

| 盒子能力 | 在智能客服中的应用 |
|---------|------------------|
| 本地知识库 | 产品FAQ/政策文档本地存储，离线也能回答 |
| 混合智能 | 简单问答本地处理（免费），复杂问答云端调用（按量） |
| 微信集成 | 盒子对接微信，自动接收和回复消息 |
| 数据不出域 | 客户对话数据全在本地，隐私安全 |
| AI Agent工作流 | 可编排"客户咨询→自动回复→记录→日报"工作流 |

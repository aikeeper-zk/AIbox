# 🌱 笔记发芽 Skill

## 概述

**不只帮你记住，更能帮你「想到」**。

「笔记发芽」是受 **得到大脑（原Get笔记）的「笔记发芽」功能** 启发而设计的 AI 思考技能。它的核心理念是：

> 你每天说的话、读的书、冒出来的想法，都是种子。大多数工具只负责把种子存起来——发芽要做的，是让这些种子**长出新认知**。

发芽不是搜索（搜索是检索和罗列），它是**理解和连接**。AI 会理解你内容的思想内核，然后跨领域、跨时空地找到"远方的回响"。

---

## 核心理念：笔记不是博物馆，是花园

| 传统方式 | 发芽方式 |
|---------|---------|
| 📦 笔记是仓库，存进去就不动了 | 🌱 笔记是种子，可以不断生长 |
| 🏛️ 知识库是博物馆"只进不出" | 🌿 知识库是花园"持续萌发" |
| 🔍 你要主动去搜才能找到 | 🤖 AI 主动送你关联内容 |
| 📁 文件夹隔离，笔记之间没路 | 🌐 AI 帮你修路，跨域碰撞 |

**理论基础**：
- **远距离联想理论（Mednick, 1960s）**：有创造力的人和普通人的区别不是"想得更多"，而是联想的距离更远
- **慢直觉（Steven Johnson《好创意从哪里来》）**：伟大创意多数是想法潜伏很久后，与不相关的信息碰撞的产物

## 什么时候用

### ✅ 触发场景

| 场景 | 示例 |
|------|------|
| **金句收藏** | 记录一句触动你的话，找到古今中外不同领域的共鸣表达 |
| **读书听课** | 录下几句感想，AI 从你没想到的角度给出跨学科关联知识 |
| **灵感发散** | 记录一个初步想法，从不同维度延展思考，激发更多创意 |
| **会议复盘** | 对关键议题发芽，发现其他行业或历史中的类似案例 |
| **日常感悟** | 随口记录生活感触，发现背后更深层的规律和连接 |
| **内容深化** | 读完一篇文章想获得更深层的理解，不只停留在表面信息 |

### ❌ 不要用发芽

- **纯搜索/检索**：「帮我查一下XX是什么」→ 走搜索工具
- **纯润色**：「帮我顺一下这段话」→ 走润色
- **渠道内容创作**：「写成小红书/公众号」→ 走创作技能
- **纯总结摘要**：「帮我总结这篇文章」→ 走总结技能

> **发芽 vs 创作**的边界：用户想**跨界联想、看看别的领域有什么类比** → 走发芽；用户想**落成具体渠道的内容** → 走创作。

## 工作流程

当用户触发「发芽」时，按以下流程执行：

### Step 1：判断材料类型

- 如果是**一句话/金句**：直接提取思想内核
- 如果是**文章/笔记**：提取标题、核心观点、关键论据
- 如果是**对话/想法碎片**：整理成可分析的结构化输入

### Step 2：提炼思想内核

用 1-2 句话概括材料的本质——不是复述表面内容，而是挖掘深层含义。

> 例如：「既往不恋，当下不杂，未来不迎」→ 思想内核是"活在当下"

### Step 3：选择发芽方向

从以下方向中自动选择 2-3 个最有价值的：

| 方向 | 说明 | 适用材料 |
|------|------|---------|
| 深度解读 | 提供理论框架、历史背景、机制分析 | 简短金句、感悟 |
| 横向关联 | 连接其他领域的类似现象、对比案例 | 单一案例、观点 |
| 批判性视角 | 提供反面案例、潜在风险、不同观点 | 乐观/单一视角材料 |
| 实践应用 | 提供可操作的方法、当代应用场景 | 理论、历史材料 |
| 哲学升华 | 提升到哲学、文化、人性层面 | 有深刻洞察的材料 |

### Step 4：生成发芽报告

每个发芽方向输出三层结构：

```
🌱 种子 —— 重新框定核心观点，提供新视角（80-120字）
📖 故事 —— 历史案例/科学/文化现象，含具体事实（250-350字）
✨ Aha瞬间 —— 反直觉金句，提炼综合洞察（20-40字）
```

### Step 5：输出「你的思考空间」

引导用户进一步思考，包含三个层面：

- **应用层面**：这个洞察可以用在哪里？
- **批判层面**：这个观点有什么局限或反面？
- **关联层面**：这个话题还能和什么连起来？

## 内置发芽提示词（System Prompt）

当需要执行发芽任务时，使用以下 system prompt 调用模型：

```
# 角色定义

你是一个材料发芽专家，擅长从已保存的文章、微博等材料中提取深层价值，通过故事化扩展和多维度关联，将"读过的内容"转化为"自己的洞察"。你的语言风格有文学性，善于用具体事实和戏剧性叙事制造"认知冲击"。

# 任务

深度分析用户提供的材料，生成一份完整的"发芽报告"，包含2-3个发芽方向，每个方向有"种子→故事→Aha瞬间"的叙事结构，以及最后的"思考空间"。

✨ Aha 瞬间

"[金句，20-40字，提炼材料+故事的综合洞察，追求反直觉或升华]"

---

## 发芽 02：[方向标题]

（同上结构）

---

## 💭 你的思考空间
```

## 输出示例

用户输入：「既往不恋，当下不杂，未来不迎——曾国藩」

生成报告：

> # 一句古训的跨界回响 🌱 发芽报告
>
> ## 材料核心
>
> 曾国藩这句话的核心是"活在当下"——不纠结过去、不杂念当前、不焦虑未来。
>
> ---
>
> ## 发芽 01：东西方智慧的共振
>
> 🌱 种子
>
> 东方古训"活在当下"并非孤独的声音。20世纪西方物理学和哲学几乎同时抵达了同样的终点——时间是一种幻觉，唯一真实的是"此刻"。
>
> 爱因斯坦在晚年给逝去友人贝索的家属写信时写道："现在他比我先行一步，离开了这个奇怪的世界。但这并不意味着什么。对于我们这些相信物理的人来说，过去、现在和未来的区别不过是一种顽固的幻觉。"这位物理学巨匠用相对论的逻辑推导出了与曾国藩几乎相同的结论。
>
> 而《功夫熊猫》里乌龟大师对阿宝说的那句"昨天是历史，明天是谜题，但今天是上帝的礼物"，用最通俗的方式完成了这场跨越2500年的对话。
>
> ✨ Aha 瞬间
>
> "最深的智慧往往殊途同归，区别只在于表达它的语言和时代。"
>
> ---
>
> ## 💭 你的思考空间
>
> 基于这些发芽，你可以思考：
>
> **应用层面**
> - 当你焦虑未来时，哪些事情是"此刻真正可控的"？
> - 如何把"活在当下"转化为日常可执行的行为准则？
>
> **批判层面**
> - "不念过去"是否意味着我们不该从历史中学习？活在当下和长远规划矛盾吗？
>
> **关联层面**
> - 这个理念还能和哪些领域的核心思想对话？（比如禅宗的"正念"、斯多葛学派的"控制二分法"）

## 通用纪律

1. **从材料出发**：每个发芽方向必须与原始材料形成对话，不能脱离材料空谈
2. **有事实支撑**：故事必须有具体人名、时间、事件、数据
3. **不编造**：素材里没有的东西绝不脑补虚构
4. **不硬扯**：关联要自然、有说服力，不能为了"跨界"而胡乱联想
5. **守住边界**：用户想发芽就给发芽，不擅自加私货、不往创作渠道转化

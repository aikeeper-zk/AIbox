# 腾讯产品经理能力模型

> 来源：《腾讯产品经理能力模型_产品类》，本文件是PM能力自评与成长路径的完整参考。

## 能力框架总览

腾讯产品经理能力模型包含四大框架、19个能力项，每项按Level 1-5五级定义：

| 框架 | 能力项数 | 核心关注 |
|---|---|---|
| 通用能力 | 5 | 学习、执行、沟通、行业融入、心态情商 |
| 专业知识 | 3 | 技术知识、项目管理、其他知识 |
| 专业技能 | 7 | 产品规划、市场分析、商务沟通、运营数据、营销推广、渠道管理、用户调研 |
| 组织影响力 | 3 | 方法论建设、知识传承、人才培养 |

## 自评使用指南

### 如何做一次有效的自评

1. **诚实对标**：逐项阅读Level描述，找到自己"大部分时候能做到"的等级，而非"偶尔能做到"的最高等级
2. **区分维度**：不同维度可能处于不同等级，这是正常的——多数PM的专业技能高于组织影响力
3. **找短板**：识别当前岗位要求与实际水平的差距最大的2-3个维度，这是成长的优先级
4. **定目标**：每个短板维度设定3-6个月提升一个Level的具体行动计划

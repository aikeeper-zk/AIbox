# 微信公众号富文本排版

## 概述

将Markdown/文本内容转换为微信公众号编辑器兼容的富文本HTML。核心原则是**纯内联样式**——只用 `<section>` 和 `<p>` 标签，所有样式写在 `style=""` 属性中，不使用CSS类、外部样式表或 `<table>/<div>` 标签。这种格式可直接粘贴到公众号编辑器，不会出现样式丢失。

## 你的工作方式

1. **确认品牌配色**——询问用户指定品牌色，或从内容主题自动推断
2. **读取内容**——从workspace文件或对话历史获取原始内容
3. **排版生成**——按本技能的排版规范生成HTML
4. **导出交付**——写入workspace并提供下载链接

## 排版规范

读取 `references/format-spec.md` 获取完整排版规范（标签体系、组件库、配色方案）。以下是核心原则摘要：

### 标签铁律

- ✅ 只用 `<section>` 和 `<p>`
- ❌ 禁止 `<div>`, `<table>`, `<tr>`, `<td>`, `<th>`
- ❌ 禁止 CSS `class=""` 属性
- ❌ 禁止 `<style>` 标签或外部样式表
- ❌ 禁止 `<span>` 嵌套（用 `<strong>` 的 `style` 属性替代）

为什么？公众号编辑器会过滤CSS类和外部样式，`<table>` 在部分客户端渲染异常，`<div>` 的嵌套层级会被压缩。`<section>` + `<p>` + 纯内联style是公众号兼容性最高的组合。

### 配色方案

每篇文章使用一套品牌配色。由用户指定，或从内容主题推断：

| 推断线索 | 建议配色 |
|---|---|
| 科技/AI/GPU/芯片 | 深蓝+亮蓝（如 #1a2744 + #3b82f6） |
| 腾讯/社交/紫色品牌 | 深蓝+紫色（如 #0f3460 + #7c3aed） |
| 英伟达/绿色品牌 | 深绿+翠绿（如 #0a2618 + #2d8659） |
| 金融/严肃/官方 | 深灰+金（如 #1b263b + #c9a227） |
| 创业/活力/年轻 | 深橙+橙（如 #1a1a2e + #f97316） |

配色结构固定为5色系：

- **primary-dark**：封面渐变起点、标题条背景
- **primary**：章节标题条、表格头、强调色、分隔线
- **accent**：关键数据高亮、品牌色强调
- **red**（#c62828）：亏损、风险、挑战
- **orange**（#e65100）：警示、注意
- **green**（#2e7d32）：增长、正面、优势

### 组件库

每个组件都有固定的HTML结构和内联样式模板。读取 `references/component-templates.md` 获取所有组件的完整代码模板。以下是组件清单：

| 组件 | 用途 | 核心结构 |
|---|---|---|
| 封面区 | 文章标题+副标题+日期 | 渐变 `<section>` 包裹3个 `<p>` |
| 章节标题 | 每章开头 | 品牌色 `<section>` 条 + ①编号 `<p>` |
| 分隔线 | 章节间 | 渐变 `height:2px` 的 `<section>` |
| 正文段落 | 普通文字 | `<p style="margin:0 0 16px 0;">` |
| 数据表格 | 多列数据对比 | flex `<section>` 行，头行品牌色背景 |
| 引用块-正面 | 金句/正面洞察 | 左border品牌色+浅绿背景 `<section>` |
| 引用块-警示 | 风险/警告 | 左border橙色+浅橙背景 `<section>` |
| 引用块-危险 | 致命问题 | 左border红色+浅红背景 `<section>` |
| 引用块-信息 | 补充说明 | 左border品牌色+浅灰背景 `<section>` |
| 关键数据块 | 核心参数展示 | 深色渐变背景 `<section>` + 📌列表 |
| ✅优势卡片 | 优点/正面 | 绿色边框+浅绿背景 `<section>` |
| ❌挑战卡片 | 缺点/风险 | 红色边框+浅红背景 `<section>` |
| 数据速览 | 文章末尾汇总 | flex两列 `<section>` 表格 |
| 时间线 | 事件序列 | 📌标记的 `<p>` 列表在浅色 `<section>` 内 |

## 工作流示例

### 示例1：从已有Markdown文件转换

用户说："把燧原科技深度扒皮.md转成公众号富文本"

1. 读取 `/sandbox/workspace/燧原科技深度扒皮.md`
2. 从内容主题推断配色（燧原→深蓝+紫色）或询问用户
3. 按组件库逐章节转换：封面→①章节→分隔线→②章节→...→数据速览→尾部
4. 写入 `/sandbox/workspace/燧原科技深度扒皮_公众号富文本.html`
5. 提供 `provide_file` 下载链接

### 示例2：从对话历史内容直接生成

用户说："刚才扒的壁仞科技内容转成公众号富文本，用深蓝色"

1. 从对话历史提取壁仞科技的全部内容
2. 用户已指定配色：深蓝（primary-dark: #0d0d1a, primary: #1a2744, accent: #3b82f6）
3. 按组件库排版生成
4. 写入文件并提供下载

## 确认门

- **配色确认**：生成前确认品牌配色方案（用户指定或自动推断）
- **内容完整性**：确认所有章节都已覆盖，不遗漏重要数据

# 🌱 笔记发芽 Skill — 快速参考

## 一句话介绍
> 不只帮你记住，更能帮你「想到」。种下一颗种子，长出新的认知。

## 触发方式

直接对任何想法/内容说：

| 你要说 | 效果 |
|--------|------|
| 「帮我把这句话发芽一下：……」 | ✅ 一句话快速发芽 |
| 「对这个想法发个芽」 | ✅ 对当前内容发芽 |
| 「帮我深度解读这段话」 | ✅ 深度发芽模式 |
| 「这条内容跨界联想一下」 | ✅ 横向关联优先 |
| 「让这个想法长出新的认知」 | ✅ 完整发芽报告 |
| 「帮我在别的领域找找类似的观点」 | ✅ 横向关联发芽 |

## 输出结构

每条发芽报告包含：

```
🌱 材料核心 —— 1-2句概括
    │
    ├─ 发芽01：[方向] → 🌱种子 → 📖故事 → ✨Aha瞬间
    ├─ 发芽02：[方向] → 🌱种子 → 📖故事 → ✨Aha瞬间
    └─ 发芽03：[方向] → 🌱种子 → 📖故事 → ✨Aha瞬间
    │
    └─ 💭 你的思考空间 → 应用/批判/关联
```

## 经典示例

> **用户**：「既往不恋，当下不杂，未来不迎——曾国藩」
>
> **发芽** → AI理解内核是"活在当下" → 关联出**爱因斯坦**的时间观 + **《功夫熊猫》**乌龟大师的金句

## 下金蛋的哲学

> 灵感不是等来的，是信息碰撞出来的。
>
> 多样化输入 × 保持困惑 × 外化记录 = 慢直觉的加速引擎

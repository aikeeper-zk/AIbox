Z-Claw 使用指南

AI 助手便携 U盘 · 三步开始使用

🚀 快速开始
启动服务
Windows  双击 Windows-Start.bat
macOS    双击 Mac-Start.command
配置 AI 模型
首次启动自动打开配置页 → 选模型 → 填 API Key → 保存
开始对话
浏览器自动打开 http://127.0.0.1:18789，即可与 AI 对话
✅

所有配置和对话记录保存在 U盘 data/ 目录，Mac 和 Windows 自动共享！

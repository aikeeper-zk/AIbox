# PPT质量评估 · 报告生成技能

> 自动分析PPTX文件的多维度质量指标，输出评分报告与优化建议

## 你的工作方式

你是**PPT质量评估专家**。使用 `scripts/analyze_ppt.py` 脚本对PPTX文件进行程序化分析，从8个维度评估质量，输出结构化报告。

**核心原则：**
- 使用 `scripts/analyze_ppt.py` 脚本分析，支持Python-pptx提取的结构化数据
- 评估基于**可量化的程序化指标**（元素位置、颜色统计、字体一致性、重叠检测等）
- 输出报告写入 `/sandbox/workspace/outputs/PPT质量评估报告-[文件名].md`
- 评估完成后将报告提供给用户，并给出针对性的优化建议
- **对生成PPT的场景**：如果用户刚生成PPT后要求评估，结合生成过程的信息理解内容背景

## 评估流程

### Step 1：确认PPT文件路径

确认用户要评估的PPT文件路径。如果是刚生成的PPT，路径通常在 `/sandbox/workspace/outputs/` 下。

如果没有明确指定，搜索常见的输出路径。

### Step 2：运行分析脚本

```bash
python3 /sandbox/workspace/skills/ppt-quality-evaluator/scripts/analyze_ppt.py /path/to/file.pptx
```

### Step 3：解读评估报告

脚本输出的报告包含：

| 维度 | 分值 | 评估内容 |
|------|------|---------|
| ① 页面结构 | 15分 | 页数合理性、页眉页脚、边距规范 |
| ② 排版布局 | 15分 | 元素重叠检测、空页率、元素密度 |
| ③ 色彩搭配 | 15分 | 颜色丰富度、亮色点缀、色彩和谐 |
| ④ 字体规范 | 15分 | 字体种类、字号层次、大标题 |
| ⑤ 内容呈现 | 15分 | 文字密度、配图数量、图表使用 |
| ⑥ 视觉一致性 | 10分 | 对齐方式统一、页面复杂度均匀 |
| ⑦ 图表数据 | 10分 | 图表数量、数据标签完整性 |
| ⑧ 比例尺寸 | 5分 | 幻灯片比例标准度 |

### Step 4：输出评分报告

将评估结果整理为用户友好的格式：

**对话中输出核心摘要：**
```
═══ PPT质量评估报告 ═══
📋 文件: [文件名]
📄 页数: [X]页 | 尺寸: [尺寸]
📊 综合得分: [X]/100 — [等级]

各维度评分：
① 页面结构: [X/15]  ████████░░
② 排版布局: [X/15]  ████████░░
③ 色彩搭配: [X/15]  ████████░░
④ 字体规范: [X/15]  ████████░░
⑤ 内容呈现: [X/15]  ████████░░
⑥ 视觉一致性: [X/10] ██████░░
⑦ 图表数据: [X/10]  ██████░░
⑧ 比例尺寸: [X/5]   ████░░

🔴 待优化项：
- [具体问题] → 建议[具体方案]
```

**同步写入文件：**
`/sandbox/workspace/outputs/PPT质量评估报告-[文件名].md`

### Step 5：给出优化建议

根据各维度得分给出针对性建议：

| 低分维度 | 常见原因 | 建议方案 |
|----------|---------|---------|
| ① 页面结构 | 缺页眉页脚/边距不统一 | 使用统一模板，添加标准页眉页脚 |
| ② 排版布局 | 元素重叠/空页/过多 | 检查重叠元素，精简页面 |
| ③ 色彩搭配 | 颜色单调/过多 | 统一配色方案，增加1-2种亮色点缀 |
| ④ 字体规范 | 字体过多/无层次 | 限制2-3种字体，建立字号层级 |
| ⑤ 内容呈现 | 文字密集/缺图 | 拆分为多页，增加配图图表 |
| ⑥ 视觉一致性 | 各页风格不统一 | 统一卡片样式和对齐方式 |
| ⑦ 图表数据 | 缺标签/缺图表 | 增加数据标签，关键数据用图表展示 |

## 典型问答示例

**Q1：帮我看看我刚生成的这份PPT质量怎么样**
A：好的，我来跑一下质量评估。先确认文件路径，然后运行分析脚本。

**Q2：给这个PPT打个分，说说什么地方需要优化**
A：收到！分析中。评估完成后会输出8个维度的详细评分，并给出每项低分的原因和改进建议。

**Q3：对比两份PPT哪个质量更好**
A：可以分别对两份PPT运行评估，然后对比各维度得分，帮你判断哪份更优以及各自的优缺点。

## 14. 模板使用指引（给FDE）

### 14.1 报告生成方式

- **手工填写**：每月5日前，FDE根据实时数据+灵虾平台截图+客户访谈填写
- **自动化生成（推荐）**：通过灵虾平台"月度报告"功能，自动抓取数据+人工补充建议
- **建议工具**：飞书多维表格 / 金山文档 / 微软Word模板

### 14.2 报告分发SOP

1. 每月5日前完成初稿 → 自审（24小时） → 提交内审
2. 内部审核（产品/技术经理复核关键数据） → 定稿
3. 客户签字前通过企微/邮件发送预览版（建议2天前）
4. 月度评审会（视频/现场）→ 客户签字确认
5. 归档至CRM+案例库

### 14.3 KPI达标判定标准

| 评级 | 标准 | 后续动作 |
|------|------|---------|
| ✅ 健康 | 12项KPI中≥10项达标 | 正常节奏，无需特别关注 |
| ⚠️ 关注 | 12项KPI中8-9项达标 | 月度评审会重点分析退步项 |
| ❌ 异常 | 12项KPI中<8项达标 | 触发P1应急+FDE团队介入 |

### 14.4 与其他模板的联动

- **故障事件** → 必须联动 `incident-report-template.md`（故障诊断报告）
- **客户反馈建议** → 必须联动 `feedback-report-template.md`（客户反馈报告）
- **升级决策** → 必须联动 `deployment-plan-template.md`（部署方案书）
- **产品建议提交** → 必须联动产品团队工单系统

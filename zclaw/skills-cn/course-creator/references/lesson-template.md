# 课时 MD 结构模板

每课正文 1000-1500 字，严格按以下结构。

```markdown
# 第X课：标题

## 概述

（300-500字，介绍本课学什么、为什么重要。用一句话钩子开头，说明本课的核心问题或痛点。）

## 核心知识点

（分3-5个知识点。每个知识点按"定义→原理→例子"三层展开。）

### 知识点1：[知识点名称]

**定义：** [一句话说清]

**原理：** [展开说明机制/逻辑/关键要点]

**例子：** [用真实案例说明]

### 知识点2：[知识点名称]

...

### 知识点3：[知识点名称]

...

## 案例与实践

（至少1个贯穿性的真实案例。说明在什么场景下、怎么用、效果如何。）

**案例：[案例名称]**

- 背景：[场景描述]
- 操作：[具体步骤或方法]
- 结果：[量化或定性的效果]
- 启示：[可迁移的经验]

## 关键概念总结

| 概念 | 说明 |
|:----|------|
| [术语1] | [一句话解释] |
| [术语2] | [一句话解释] |
| [术语3] | [一句话解释] |

（3-5个最重要的术语/概念）

## 延伸阅读

1. [标题] - [来源/链接]
2. [标题] - [来源/链接]
3. [标题] - [来源/链接]

（2-3条建议阅读的资源，注明来源）
```

## 质量标准自查

- [ ] 正文 1000-1500 字
- [ ] 至少 3 个知识点，每个三层（定义+原理+例子）
- [ ] 至少 1 个真实案例
- [ ] 关键概念表（3-5个术语）
- [ ] 延伸阅读（2-3条，含来源）
- [ ] 语言风格：专业但不晦涩，通俗但不肤浅

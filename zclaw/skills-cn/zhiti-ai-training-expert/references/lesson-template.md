# 单课时培训内容模板

## 课时结构规范

每课时正文 **1000-1500字**，严格遵循以下结构：

```markdown
# {课时编号}｜{课时标题}

## 🎯 学完这课，你能做到什么
（一句话概括本课核心收获，让学员3秒判断是否需要学）

## 📖 核心知识点

### 知识点1：{标题}
- **是什么**：定义/概念
- **为什么**：原理/逻辑
- **怎么用**：操作步骤/示例

### 知识点2：{标题}
（同上结构）

### 知识点3：{标题}
（同上结构）

## 🔧 实操演练

### 场景：{具体场景描述}
- **操作步骤**：
  1. 步骤1
  2. 步骤2
  3. 步骤3
- **预期结果**：{描述成功后的效果}
- **常见问题**：{1-2个典型问题与解决}

## 💡 话术/要点卡（面向销售/代理培训时使用）
- **客户说**："{典型客户异议}"
- **你回答**："{标准话术}"

## 📝 关键概念速查
| 术语 | 一句话解释 |
|------|----------|
| {术语1} | {解释} |
| {术语2} | {解释} |

## 📚 延伸阅读
- {相关课程/文档链接1}
- {相关课程/文档链接2}
```

## 质量标准

| 维度 | 要求 |
|------|------|
| 字数 | 1000-1500字（不含模板标记） |
| 知识点数 | 3-5个，每个含定义/原理/示例三层 |
| 实操场景 | 至少1个，含步骤/预期结果/常见问题 |
| 话术卡 | 销售/代理类课时必含，其他课时可选 |
| 术语表 | 3-5个核心术语 |
| 延伸阅读 | 2-3条 |
| 数据来源 | 优先从知识库检索（kb_id: XrneKkrCkkdLgfe-lti6VAiwoipSAe7CsltatLHrAAs=） |

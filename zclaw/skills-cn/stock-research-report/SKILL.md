# 股票深度投资研究报告生成器

将任意一只股票（A股 / 港股 / 美股）转化为**深度、可溯源、含综合研判**的投资研究报告：先通过金融数据 skill 拉取行情、财务、行业、新闻、公告、研报等多维数据，再做公司 / 行业 / 财务 / 估值 / 风险五维深挖，最终按统一模板产出**不低于 3000 字**的 Markdown 研报，并可渲染为排版精美的独立 HTML。

本 skill 的核心差异点是“深”与“综合”：

- **深**：每个结论都要有“证据 → 推理 → 结论”的链条，拒绝无依据的定性形容词；主动提出反方观点与失效条件。
- **综合**：不仅罗列维度，还要在独立章节做**多空对等辩论**、**三情景估值（乐观/中性/悲观）**与**概率加权判断**，把五维结论收敛为可执行的投资结论。

## 何时使用

当用户表达以下意图时触发本 skill：

- “帮我写一份 XX（股票）的深度研报 / 个股研究报告 / 综合分析”
- “分析一下 XX 的投资价值 / 基本面，要深入”
- “XX 值得买吗？给我一份完整、有深度的研究报告”
- 任何要求对单只股票做“深度 / comprehensive / 基本面 / 综合研判”研究的请求

不适用：指数 / ETF / 基金研究（用对应工具或 westock-tool）、纯短线技术面分析、投资组合整体回测、量化策略开发。

## 工作流

### 第 1 步：锁定标的

向用户确认或自动解析目标股票：

- 若用户给出代码（如 `600519`、`00700.HK`、`AAPL`），直接锁定；
- 若给出名称（如“茅台”“腾讯”），调用 `westock-data` 或 `wb-finance-skill` 的搜索能力解析到唯一代码 + 市场；
- 若同名多标的，列出候选让用户确认，不得代猜。

记录四项：公司全称、股票代码、所属市场（A / H / US）、所属申万 / 中信一级行业。

### 第 2 步：制定数据采集清单

按 `references/data-sources.md` 的映射调用相应 skill 获取数据。至少覆盖：

- 行情与估值：现价、总市值、PE(TTM) / 静态、PB、PS、股息率、年内涨跌幅、52 周高低、估值历史分位
- 财务：近 3–5 年营收 / 归母净利润 / 毛利率 / 净利率 / ROE / 资产负债率 / 经营现金流 / 自由现金流
- 成长性：营收与利润复合增速、一致预期（未来 2–3 年 EPS 与增速）、预期修正方向
- 行业：行业空间、增速、生命周期、产业链上下游、竞争格局（CR3/CR5）、政策与价格周期、公司在产业链位置与市占率
- 事件：近 1–3 年重大公告、高管 / 机构持仓变动、分红回购、资本开支与产能规划
- 舆情：近 3–6 个月重要新闻、卖方研报观点（**必须记录多空分歧**，不能只摘利好）
- 宏观：利率、汇率、大盘风险偏好（用于折现率与情景假设）

所有数据标注时间口径（如“截至 2026-08-07 收盘”“2025 年报”）。若某数据缺口，显式写“数据缺失”，**严禁编造**。

### 第 3 步：五维深度分析

按 `references/analysis-framework.md` 的方法执行（含波特五力、产业链拆解、杜邦、利润率桥、DCF 敏感性、情景分析、多空辩论框架）：

1. **公司质地**：业务结构与商业模式、护城河（品牌 / 网络效应 / 成本 / 牌照 / 技术，需量化证据）、管理层与历史资本配置（并购 / 分红 / 回购记录）。
2. **行业景气**：产业链位置与议价能力、生命周期、供需与集中度、政策传导路径、空间测算（可验证口径）。
3. **财务质量**：盈利真实性、现金流与利润匹配（OCF/净利润）、杜邦拆解（增长来自周转 / 利润率 / 杠杆？）、利润率桥、减值 / 商誉 / 关联交易预警。
4. **估值**：相对估值（PE / PB / PS / PEG 同业对比 + 历史分位）+ 绝对估值（DCF / 股息贴现，给出关键假设、敏感性区间）。
5. **风险**：经营 / 财务 / 估值 / 政策 / 黑天鹅，按发生概率 × 影响程度分级，每条给触发信号与下行量级。

**深度要求**：每一维都不能停留在定义与罗列，必须给出“证据 → 推理 → 结论”的链条。凡关键判断都要有数据 / 事实支撑，并**主动提出反方观点与边界条件**（“若 XX 不成立，则结论反转”）。

### 第 4 步：形成综合研判

这是本 skill 区别于“摘要式研报”的关键，必须在报告内形成独立章节：

- **多空对等辩论**：分别列出看多论据（≥3 条，附证据）与看空论据（≥3 条，附证据），不打分、不偏袒。
- **三情景估值**：给出乐观 / 中性 / 悲观三档假设（核心变量如增速、利润率、折现率、政策）下的合理价值区间，并赋概率（概率和=100%）。
- **概率加权结论**：基于情景与多空辩论，给出投资评级、6–12 个月目标价区间（非单点）、核心催化与观察点、适配风险偏好。
- 结论必须与前述分析一致，禁止无依据唱多 / 唱空，禁止为迎合用户而修改结论。

### 第 5 步：撰写报告

严格套用 `references/report-template.md` 的章节骨架与“深度要求 / 需回答的问题”撰写，用中文，数据用表格，关键结论加粗。必须包含独立的**综合研判**章节（多空辩论 + 三情景估值 + 概率加权判断）。

**篇幅底线**：正文（不含封面与免责声明）**不低于 3000 字（中文字符）**。建议各章节最低字数：摘要 200、研究方法与口径 150、公司概况 400、行业分析 550、财务分析 650、估值分析 550、综合研判 500、风险 350，合计即超过 3000 字；**宁可深挖，不要为凑字数空谈**。若某章偏薄，先补分析再交付。

产出文件 `stock_research_<代码>_<日期>.md`，放置于当前工作目录。

### 第 6 步（可选）：渲染 HTML

如需精美排版与可打印 / 可分享版本，调用 `scripts/build_report.py`：

```bash
python <skill-root>/scripts/build_report.py \
  --md <report.md> --meta <meta.json> --out <report.html>
```

`<skill-root>` 为本 SKILL.md 所在目录。`meta.json` 字段说明见 `references/report-template.md` 末尾。脚本零外部依赖，输出单文件 HTML（含封面、评级徽章、指标卡、目录导航、表格样式），可直接用浏览器打开或打印为 PDF。

## 深度与篇幅要求

- 报告是“研究”而非“摘要”：每个结论都要能回溯到数据或逻辑链，拒绝无依据的定性形容词（如“龙头地位稳固”须配市占率与趋势数据）。
- 必须做**多空对等论证**：在综合研判章节显式列出反面证据与失效条件。
- 必须做**情景分析**：给出乐观 / 中性 / 悲观三档假设下的估值区间与对应概率，而非单一目标价。
- 必须做**综合研判**：把五维结论收敛为一句话投资逻辑、评级、概率加权目标价区间、关键催化与主要风险。
- 交付前用下方清单核对篇幅与深度；若某章偏薄，先补分析再交付。

## 质量自检清单

交付前逐项核对：

- [ ] 标的唯一且代码 / 市场正确
- [ ] 所有数据有来源与时间口径，无编造
- [ ] 五维分析齐全且每维含“证据→推理→结论”链条
- [ ] 估值同时含相对与绝对视角，并给出敏感性 / 情景区间
- [ ] 含独立综合研判章节：多空对等辩论 + 三情景估值 + 概率加权结论
- [ ] 评级与目标价区间有分析支撑，且与正文一致
- [ ] 风险章节真实、分级、含触发信号与下行量级
- [ ] **正文 ≥ 3000 字（中文字符）**
- [ ] 报告套用统一模板，结构完整
- [ ] 末尾附“风险提示与免责声明”

## 重要声明

研报为基于公开数据的分析辅助，**不构成任何投资建议**。在报告末尾固定附“风险提示与免责声明”：市场有风险，投资需谨慎；本报告基于公开信息整理，可能存在滞后与误差，读者应独立判断并自担风险。
